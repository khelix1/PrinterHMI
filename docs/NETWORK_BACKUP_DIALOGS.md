# Network and backup dialogs

WiFi Networks shows complete network names and signal strength in dBm. Native rows grow to their content, and the list scrolls below a wrapped status area. Every supplied result is reachable. Selecting a network preserves its complete SSID callback identity; row deletion releases its copied name. Password entry stays masked and bounded to 64 characters. Its keyboard and Back/Connect actions remain pinned while contextual content scrolls. A credential-save, configuration or connection-start failure keeps input and an inline explanation. Accepted connection startup closes the editor; the Network page owns subsequent connection state.

Moonraker Port uses a numeric keyboard, five-digit limit and strict range validation (1–65535). Invalid input remains editable; Save dispatches the captured callback once after closing. Connection-test results retain full wrapped messages and a compact Close action. External deletion clears owned state so dialogs can reopen safely.

Configuration Backup separates plain/encrypted file paths, local status and native wrapping actions. Plain backups continue to exclude API keys; encrypted backups include them. Passphrase entry remains masked; the worker accepts 12–96 UTF-8 bytes and requires matching confirmation for export. Validation and worker-start errors are shown in that editor while retaining input. Focus selects the matching keyboard field and brings it into view.

Restore shows the existing verified summary (schema/profile count, active printer and included settings/key policy) and explains that profiles, appearance/display and notification settings will be replaced. Only explicit Restore applies it. Failure retains the review for retry; Cancel applies nothing. Encrypted verification transfers the staged passphrase to this confirmation, and cancellation/completion/external deletion clears it. Removal retains its separate explicit confirmation and uses the existing backup-only deletion API. Encrypted-worker progress displays complete status and WORKING with the existing phase indicator; it does not claim a measured completion percentage or add unsupported cancellation. Closing an owner retires its timers and prevents orphaned confirmations; the storage worker retains its own execution lifecycle.
