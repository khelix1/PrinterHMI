# Theme previews

Built-in theme choices show miniature dashboards rather than a shared nozzle card. Foundry uses a larger print panel and warm workshop surfaces. Operator retains balanced print/instrument panels. Operator Shell gives the active job more space beside a compact instrument column. Dark Glass shows two separate instrument tiles and shaded glass surfaces. These four previews retain the production shell's eight-item left rail, status banner and bottom actions. Their print/instrument proportions come from `ui_dashboard_layout_profile_for_theme()`.

Studio shows its open dashboard heading, borderless model well, divided thermal instruments, purple progress track and eight-item bottom dock. The dock paths come from the same native icon owner used by Studio. Previews are illustrative sample data, not live printer readings or scaled screenshots.

Each miniature has a shared scene definition for both cached RGB565 drawing and the native allocation fallback. Fonts belong to the requested preview rather than the active theme or accessibility text size; chooser headings still follow the selected accessibility settings. The cached scene is drawn once and scrolling copies its pixels. Deletion drops the image-cache reference before freeing its PSRAM buffer. Theme apply, selection highlighting, deferred rebuilding and custom-theme handling retain their existing behavior.

Run `tools/audit/theme_dialog_layout_test.py` against LVGL 9.5. The actual owner suite checks all five active themes, three densities, normal/large text and standard/narrow/short viewports; switching, selection/removal failures, deduplication, scroll occlusion and cleanup. Miniature checks additionally cover five requested themes at 280/360/440 px widths, complete label and child bounds, byte-identical cached scene data across active themes/text settings, and pixel-identical cached/fallback rendering. Host renders were inspected. Firmware build and panel theme selection/scrolling remain pending, along with previously documented printing/recovery tests. Stable remains 6.5.6; the feature branch remains open.
