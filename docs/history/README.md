# Historical engineering records

This directory preserves the original v3.x architecture, roadmaps, reviews,
crash records and refactor logs. They are valuable evidence of design decisions
but do not describe the current v6.4.0 product.

## Layout

- `architecture/` — v3.2 and v3.3 ownership plans
- `development/` — source catalogs, code reviews, crash and refactor logs
- `planning/` — superseded roadmaps and block-review plans
- `bringup/` — inherited vendor README and early v3.0 build/OTA notes

Historical files are retained substantially verbatim. Broken links, obsolete
paths, old component versions and completed tasks inside them are expected.
Do not use them as build or recovery instructions.

Current documentation begins at [`../README.md`](../README.md).
