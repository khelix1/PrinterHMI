# PrinterHMI v4.1.0

PrinterHMI v4.1.0 is the capability and operator-hardening release for the
ESP32-P4/ESP32-C6 PrinterHMI appliance.

## Highlights

- Capability-aware controls for up to four independently controlled hotends
- Live active-hotend selection and temperature control
- Switch and motion filament-sensor discovery and live state
- Operator event history
- Configuration backup and restore
- Auto-scaling telemetry without chart sliders
- More reliable multi-printer WebSocket rebinding and recovery
- Smoother OTA keyboard and progress-popup transitions
- Cancellable OTA downloads with verified final image handling
- Improved printer connection failure states

## Compatibility

- Hardware: JC1060P470C-I/W, ESP32-P4 with ESP32-C6 hosted Wi-Fi
- ESP-IDF: 5.4.4
- OTA layout: compatible with the PrinterHMI v4.0.0 dual-slot layout
- Moonraker: HTTP and WebSocket endpoints

## Upgrade

Install the `PrinterHMI-v4.1.0-ota.bin` release asset through the Settings OTA
screen. Existing printer profiles, display settings and configuration remain
compatible.

## Verification

The release was exercised through cold boot, warm reboot, full power cycle,
display sleep/wake, printer switching, Klipper/Moonraker restart recovery,
printing controls, previews, telemetry, backup/restore and OTA.

The accompanying `.sha256` file verifies the integrity of the downloaded
firmware bytes.
