# PrinterHMI v4.2.0

PrinterHMI v4.2.0 is the custom-theme and LVGL modernization release for the
ESP32-P4/ESP32-C6 PrinterHMI appliance.

## Highlights

- Versioned `.phmitheme` packages loaded from SD storage
- Custom palette, metrics and per-page layout geometry
- On-device custom-theme previews, selection and protected removal
- Persistent custom-theme identity with configuration backup/restore
- Safe fallback to the built-in Foundry, Operator or Dark Glass theme
- LVGL 9.5.0

## Compatibility

- Hardware: JC1060P470C-I/W, ESP32-P4 with ESP32-C6 hosted Wi-Fi
- ESP-IDF: 5.4.4
- LVGL: 9.5.0
- OTA layout: compatible with the PrinterHMI v4.0.0 dual-slot layout
- Custom-theme schema: `printerhmi.theme` version 1

## Upgrade

Install the `PrinterHMI-v4.2.0-ota.bin` release asset through the Settings OTA
screen. Existing printer profiles, display settings and configuration remain
compatible. Custom themes are stored under `PrinterHMI/themes` on the SD card.

## Verification

The release was built with ESP-IDF 5.4.4 and exercised on target hardware
through startup, navigation, built-in themes, popups, previews, telemetry,
scrolling and display sleep/wake.

The accompanying `.sha256` file verifies the integrity of the downloaded
firmware bytes.
