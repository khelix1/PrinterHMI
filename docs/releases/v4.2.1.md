# PrinterHMI v4.2.1

PrinterHMI v4.2.1 adds a secure, on-device stable and nightly release browser
to the ESP32-P4/ESP32-C6 PrinterHMI appliance.

## Highlights

- Stable releases and identity-aware nightlies loaded from the official
  PrinterHMI GitHub repository
- Dedicated `STABLE` and `NIGHTLY` tabs
- `INSTALLED`, `UPDATE` and `OLDER` status for compatible releases
- Exact installed-state recognition for nightly firmware
- Publication date, firmware size and release-note details
- Confirmed installation through the existing OTA progress, cancellation,
  validation, rollback and reboot pipeline
- Explicit downgrade, nightly-development and same-version reinstall warnings
- Custom OTA URL access for local firmware servers
- Refresh and connection-error handling

## Security and reliability

- GitHub API and firmware downloads use ESP-IDF's trusted certificate bundle.
- Stable entries require a non-draft semantic tag and the exact
  `PrinterHMI-vX.Y.Z-ota.bin` asset.
- Nightly entries require a strict `nightly-YYYY-MM-DD-<commit>` prerelease,
  the exact matching firmware asset and matching firmware-identity metadata.
- Legacy nightlies without trustworthy embedded identity are intentionally
  hidden.
- The catalog response, parsed entries, worker stack, synchronization state
  and selected-release state prefer PSRAM.
- Catalog networking and JSON parsing run outside the LVGL task.
- GitHub firmware redirects use an expanded HTTP transmit buffer.
- OTA image validation and rollback behavior remain owned by the existing OTA
  manager.

## Compatibility

- Hardware: JC1060P470C-I/W, ESP32-P4 with ESP32-C6 hosted Wi-Fi
- ESP-IDF: 5.4.4
- LVGL: 9.5.0
- OTA layout: compatible with the PrinterHMI v4.0.0 dual-slot layout
- Configuration and custom-theme formats: unchanged from v4.2.0

## Upgrade

Install `PrinterHMI-v4.2.1-ota.bin` using the OTA screen. Existing printer
profiles, Wi-Fi configuration, display settings and custom themes remain
compatible.

After v4.2.1 is installed, future stable versions and compatible nightly builds
can be selected directly from Settings, OTA Update.

## Verification

The release is built with ESP-IDF 5.4.4 and requires the standard on-target
release checks: startup, network connection, stable and nightly catalog
loading, current-version identification, exact nightly installed-state
detection, same-version reinstall confirmation, custom local OTA access,
OTA cancellation, successful OTA reboot and rollback safety.

The accompanying `.sha256` file verifies the integrity of the downloaded
release asset.
