# PrinterHMI v4.2.2

PrinterHMI v4.2.2 improves the consistency and accuracy of live print status
throughout the operator interface.

## Highlights

- Active print filename presented consistently on the Dashboard and Printer page
- Moonraker `virtual_sdcard.progress` used as the primary progress source
- Shared Remaining and ETA calculations across all live-print views
- Actual completion clock shown as ETA in the top bar
- Corrected positive volumetric-flow display during retractions
- Reduced insignificant idle-flow noise
- Completed prints show `0:00` remaining

## Live print status

The Dashboard, Printer page and top bar now use the same controller-owned timing
calculation. Remaining time is presented as a duration, while ETA is presented
as the estimated local completion time.

Progress is sourced from `virtual_sdcard.progress` when available, with
`display_status.progress` retained as a compatibility fallback.

## Reliability

- Unknown or insufficient print progress continues to display `--:--`.
- Completed jobs report zero remaining time.
- Existing Moonraker and printer-profile compatibility is unchanged.
- Existing OTA validation, cancellation, rollback and reboot behavior is
  unchanged.

## Compatibility

- Hardware: JC1060P470C-I/W, ESP32-P4 with ESP32-C6 hosted Wi-Fi
- ESP-IDF: 5.4.4
- LVGL: 9.5.0
- OTA layout: compatible with the PrinterHMI v4.0.0 dual-slot layout
- Configuration, printer-profile and custom-theme formats: unchanged from
  v4.2.1

## Upgrade

Install `PrinterHMI-v4.2.2-ota.bin` using the OTA screen. Existing printer
profiles, Wi-Fi configuration, display settings and custom themes remain
compatible.

## Verification

Before publication, complete the standard release checks:

- clean ESP-IDF build
- startup and network connection
- active filename, progress, flow, Remaining and ETA on a live print
- paused and resumed print timing
- completed-print `0:00` remaining behavior
- OTA installation, reboot and rollback safety

The accompanying `.sha256` file verifies the integrity of the downloaded
release asset.
