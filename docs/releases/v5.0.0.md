# PrinterHMI v5.0.0

PrinterHMI v5.0.0 is the operator-workflow and diagnostics release. It
promotes Bed Mesh, detected Klipper macros and the live console to first-class
HMI destinations while preserving the shared theme, control and Moonraker
ownership model.

## Highlights

- Reorganized the sidebar into ten workflow-oriented destinations: Dashboard,
  Printer, Files, Bed Mesh, Macros, Console, Telemetry, Drybox, Network and
  Settings.
- Promoted Bed Mesh from a BED-card long press to a dedicated page.
- Added a solid height-colored 3D mesh with optional surface lines, rear X/Y/Z
  reference planes, origin markers and minimum, maximum and range statistics.
- Added drag rotation, responsive pinch zoom and two-finger graph panning.
- Added Bed Mesh calibration and profile management using detected Klipper
  profile state.
- Added a dedicated console with bounded command/response history, JSON-safe
  command transport and error/warning classification.
- Added automatic discovery of public Klipper `gcode_macro` objects, hiding
  underscore-prefixed helper macros and requiring confirmation before running.
- Recorded macro executions in Console history.

## Architecture and memory

- Reused the shared runtime themes, semantic buttons, modal popups, standard
  page geometry and existing Moonraker command transport.
- Added focused `macro_controller`, `ui_macros_v32`, `console_controller` and
  `ui_console_v32` owners.
- Kept macro and console history bounded and PSRAM-first.
- Moved the Macros page runtime context and persistent shell pointer tables
  into permanent PSRAM allocations performed after scheduler startup.
- Restored internal startup-RAM headroom required by the statically allocated
  FreeRTOS timer task.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel
- ESP-IDF: 5.4.4
- LVGL: 9.5.0
- OTA layout: compatible with the PrinterHMI v4.0.0 dual-slot layout
- Existing Wi-Fi, printer profiles, themes and display settings are retained

## Installation

Install `PrinterHMI-v5.0.0-ota.bin` using the stable OTA release browser or
the custom OTA URL path. Keep power connected through the first boot, then
verify a warm reboot and full power cycle.

## Required verification

- Confirm startup reaches `main_task: Calling app_main()` without a
  `vApplicationGetTimerTaskMemory` assertion.
- Confirm all ten sidebar destinations fit and open.
- Exercise Bed Mesh rotation, pinch zoom, two-finger pan, calibration and
  profile management.
- Confirm public macros are detected, helper macros remain hidden and a safe
  macro executes only after confirmation.
- Send a known Console command and an unknown command; verify normal responses
  remain white and errors render red.
