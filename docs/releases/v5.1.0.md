# PrinterHMI v5.1.0

PrinterHMI v5.1.0 is the guided-calibration and capability architecture
release. It extends the v5 operator interface with printer-aware Calibration
and Devices workspaces while preserving the established Moonraker transport,
theme, popup and controller boundaries.

## Highlights

- Added a capability-aware Calibration workspace driven by the active
  printer's reported Klipper objects and available commands.
- Added guided PID, Input Shaper, Axis Twist, Z Tilt, Pressure Advance,
  Probe Z and custom calibration paths.
- Added shared manual-probe controls and explicit confirmation before
  persistent SAVE_CONFIG operations.
- Added a capability-aware Devices catalog with category filters, pagination
  and live values for hotends, bed, fans, drybox devices, toolhead and
  filament sensors.
- Added printer-action resolution and calibration session tracking so UI
  workflows remain separate from command and capability policy.

## Architecture and memory

- Split Calibration into page composition, motion workflows, Pressure
  Advance and shared manual-probe modules.
- Split Bed Mesh into page composition, gestures, RGB565 rendering and
  profile controls around the existing snapshot controller.
- Split Devices into page composition, catalog view, live-value adapter and
  catalog controller.
- Preserved the existing Console and Macros page/controller boundaries.
- Kept long-lived feature state bounded and PSRAM-first with internal-RAM
  fallback where appropriate.
- Added a repeatable v5 feature-architecture ownership audit.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel
- ESP-IDF: 5.4.4
- LVGL: 9.5.0
- OTA layout: compatible with the PrinterHMI v4.0.0 dual-slot layout
- Upgrade path: direct OTA from v5.0.0
- Existing Wi-Fi, printer profiles, themes, display settings and SD data are
  retained

## Installation

Install `PrinterHMI-v5.1.0-ota.bin` using the stable OTA release browser or
the custom OTA URL path. Keep power connected through the first boot, then
verify a warm reboot and full power cycle.

## Required verification

- Confirm startup reaches `main_task: Calling app_main()` without a
  `vApplicationGetTimerTaskMemory` assertion.
- Confirm all ten sidebar destinations fit, highlight and open.
- Exercise the available Calibration workflows, Back behavior, cancellation
  and SAVE_CONFIG confirmations with the printer in a safe state.
- Exercise Bed Mesh rotation, pinch zoom, two-finger pan, calibration and
  profile management.
- Exercise Devices filters, horizontal scrolling, pagination, live values and
  Telemetry navigation.
- Confirm public Macros and Console command/response behavior remain intact.
- Verify OTA from v5.0.0, first-boot validation, warm reboot and full power
  cycle.
