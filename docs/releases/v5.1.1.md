# PrinterHMI v5.1.1

PrinterHMI v5.1.1 is a network-transport stability patch for the v5.1
Calibration and Devices release. It retains the v5.1.0 interface and feature
architecture while hardening the ESP32-P4 to ESP32-C6 hosted-Wi-Fi path used
by Devices and OTA workflows.

## Fixed

- Matched the P4 ESP-Hosted component to the installed ESP32-C6 firmware at
  version 2.12.8, avoiding an unsupported host/co-processor version mismatch.
- Kept the capability-aware Devices subscription stable for the lifetime of
  the active Moonraker WebSocket instead of changing it when the page opens
  or closes.
- Quiesced competing network producers before OTA transfer and discarded
  stale WebSocket callbacks after the client is detached.
- Preserved host TX byte transfers with RX block transfers to avoid the
  ESP-Hosted block-only TX failure that reports SDIO timeout 0x107.
- Added a boot-time co-processor version log so future host/C6 mismatches are
  visible in target diagnostics.

## Reproducible build behavior

- Pinned `espressif/esp_hosted` to 2.12.8.
- Added a guarded CMake configuration hook that reapplies the tested TX-byte,
  RX-block setting whenever managed components are regenerated in a clean
  checkout.
- Kept ESP-IDF at the known-good 5.4.4 release and SDIO at 40 MHz.

## Validation

- Confirmed both P4 host and C6 co-processor report ESP-Hosted 2.12.8.
- Confirmed 4-bit SDIO initializes at 40 MHz in streaming mode.
- Completed repeated Devices-to-OTA workflows without an unrecoverable SDIO
  restart.
- Completed OTA download, image validation and reboot successfully multiple
  times on the target panel.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 5.4.4
- ESP-Hosted host and C6 firmware: 2.12.8
- LVGL: 9.5.0
- OTA layout: unchanged from v5.1.0
- Upgrade path: direct OTA from v5.1.0

## Installation

Install `PrinterHMI-v5.1.1-ota.bin` using the stable OTA release browser or
the custom OTA URL path. Existing Wi-Fi, printer profiles, themes, display
settings and SD-card data are retained.
