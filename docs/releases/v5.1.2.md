# PrinterHMI v5.1.2

PrinterHMI v5.1.2 corrects the ESP32-P4/ESP32-C6 hosted-network regression
found after v5.1.1 and retains the complete v5.1 Calibration, Devices and
multi-printer feature set.

## Fixed

- Pinned the P4-side `espressif/esp_hosted` component to 2.9.3, the stable
  host release verified on the target panel.
- Retained the installed ESP32-C6 co-processor firmware at 2.12.8. This
  deliberate pairing avoids the P4-side SDIO regression while preserving the
  working co-processor firmware.
- Removed the obsolete 2.12.8 TX-byte/RX-block managed-component patch.
- Serialized background HTTP requests so only one short transaction uses the
  hosted transport at a time.
- Reserved exclusive transport ownership for blocking Wi-Fi scans and actual
  firmware downloads.
- Allowed the GitHub release catalog to remain a serialized shared request so
  starting Custom URL OTA while the catalog is loading cannot lose the OTA
  window or reject the update.
- Expanded the temporary PSRAM GitHub release buffer to 256 KiB. The public
  release response had grown beyond the previous 128 KiB limit.
- Added operator-visible OTA startup errors and serial release-catalog failure
  diagnostics.

## Preserved behavior

- Active-printer WebSocket telemetry and capability discovery
- Inactive-printer health checks and stored preview restoration
- Capability-aware Devices catalog and stable object subscription
- Stable, Nightly and Custom URL OTA paths
- OTA cancellation, validation and rollback handling
- ESP-IDF 5.4.4, LVGL 9.5.0 and 40 MHz four-bit SDIO configuration

## Validation

- Confirmed the target boots with P4 host 2.9.3 and C6 firmware 2.12.8.
- Confirmed chooser status and previews populate normally.
- Confirmed repeated printer switching remains stable.
- Confirmed the Devices page discovers and displays the active printer.
- Confirmed Stable and Nightly GitHub release catalogs load successfully.
- Confirmed Custom URL OTA starts and completes normally.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 5.4.4
- ESP-Hosted P4 host component: 2.9.3
- ESP32-C6 co-processor firmware: 2.12.8
- LVGL: 9.5.0
- OTA layout: unchanged
- Upgrade path: direct OTA from v5.1.0 or v5.1.1

## Installation

Install `PrinterHMI-v5.1.2-ota.bin` through the Stable release browser or
the Custom OTA URL path. Existing Wi-Fi credentials, printer profiles, themes,
display settings and SD-card data are retained.
