# PrinterHMI v6.0.0

Release date: 2026-08-01

PrinterHMI v6.0.0 is a major networking-platform release. It migrates the
ESP32-P4 application to ESP-IDF 6.0.2 and upgrades both sides of the hosted
Wi-Fi link to ESP-Hosted 3.0.5 with RPC v2.

## Highlights

- Upgraded the ESP32-P4 application from ESP-IDF 5.4.4 to ESP-IDF 6.0.2.
- Upgraded the P4 host and ESP32-C6 co-processor to ESP-Hosted 3.0.5.
- Upgraded `esp_wifi_remote` to 1.5.3.
- Negotiates RPC v2 with matching 3.0.5 firmware on both processors.
- Runs the four-bit hosted SDIO transport at 40 MHz with the verified
  active-low co-processor reset configuration.
- Restored reliable SD-card mounting on the ESP-IDF 6 hardware path.

## Fixed

- Eliminated the crashes seen while changing active printers during prints.
- Eliminated the related OTA instability on the previous hosted-network stack.
- Removed obsolete fixed settling delays and readiness gates that made printer
  changes appear offline or blank for several seconds.
- Retained generation fencing so events from a retired printer connection
  cannot update the newly selected printer.
- Retained exclusive network ownership for OTA while allowing ordinary
  printer transitions to reopen immediately.
- Prevented the release catalog from competing with an active OTA download.
- Added live top-bar Wi-Fi signal bars based on real station RSSI.
- Added the missing ESP-Hosted 3.0.5 host-side request and response dispatch
  for `WifiStaGetRssi`.
- Visually distinguishes inactive Wi-Fi bars from active signal bars.

## Build reproducibility

- Added `tools/build_idf6_hosted3.sh` as the canonical firmware build.
- The build explicitly selects ESP-IDF 6.0.2, `sdkconfig.idf6` and
  `build-idf6-hosted3`.
- Added a tracked, guarded patch for the four missing ESP-Hosted 3.0.5 RSSI
  RPC dispatch locations.
- Stable and nightly release scripts now use the same canonical build path.

## Validation

- Confirmed ESP-Hosted reports host 3.0.5 and co-processor 3.0.5 with RPC v2.
- Confirmed Wi-Fi association, DHCP, SNTP and Moonraker WebSocket operation.
- Confirmed repeated printer selection is responsive and retains live state.
- Confirmed printer changes no longer crash during active prints.
- Confirmed Stable/Custom OTA completes and the new image is marked valid.
- Confirmed SD-card mounting on the target panel.
- Confirmed live RSSI updates and correct top-bar signal levels.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 6.0.2
- ESP-Hosted P4 host component: 3.0.5
- ESP32-C6 co-processor firmware: 3.0.5
- ESP Wi-Fi Remote: 1.5.3
- LVGL: 9.5.0
- OTA partition layout: unchanged

## Important upgrade requirement

Firmware v6.0.0 requires ESP-Hosted 3.0.5 on the ESP32-C6 co-processor.
Devices still using the v5.1.2 pairing of P4 host 2.9.3 and C6 firmware
2.12.8 must first flash `PrinterHMI-v6.0.0-c6-3.0.5-transition-full-flash.bin` over USB.
After the transition finishes, install the normal v6.0.0 OTA application.

Do not install the v6.0.0 application onto a device whose C6 co-processor
still runs 2.12.8.

## Installation

For a device already migrated to C6 firmware 3.0.5, install
`PrinterHMI-v6.0.0-ota.bin` through the Stable release browser or Custom OTA
URL. Existing Wi-Fi credentials, printer profiles, themes, display settings
and SD-card data are retained.
