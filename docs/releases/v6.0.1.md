# PrinterHMI v6.0.1

Release date: 2026-08-02

PrinterHMI v6.0.1 completes the v6 platform migration by making the entire
current P4+C6 firmware stack reproducible from a fresh repository checkout.

## Added

- Added `tools/build_v6_stack.sh` to build and package both processors.
- Added optional `--bootstrap` installation of the exact ESP-IDF 6.0.2 tag.
- Added normal ESP32-P4 OTA and full-flash images.
- Added ESP32-C6 ESP-Hosted 3.0.5 application and full-flash images.
- Added component images, `STACK_MANIFEST.json`, `FLASHING.txt` and internal
  SHA-256 verification.
- Added a checksummed GitHub-ready full-stack archive.

## Changed

- ESP-IDF 6.0.2 is now the only active build toolchain for current firmware.
- Stable publication builds the complete stack directly from the tagged
  source instead of depending on an external transition-host binary.

## Validation

- Built the P4 application and C6 firmware successfully.
- Verified all internal file checksums and the outer archive checksum.
- Verified the P4 application is embedded at `0x20000` in its full image.
- Verified the C6 application is embedded at `0x10000` in its full image.
- Retained the runtime behavior validated for v6.0.0: matching ESP-Hosted
  3.0.5, RPC v2, responsive printer switching, OTA, live RSSI and SD storage.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 6.0.2
- ESP-Hosted P4 and C6: 3.0.5
- ESP Wi-Fi Remote: 1.5.3
- LVGL: 9.5.0
- OTA partition layout: unchanged

## Installation

If the C6 already runs ESP-Hosted 3.0.5, install
`PrinterHMI-v6.0.1-ota.bin` normally. For initial installation or direct
recovery, download the full-stack archive and follow its `FLASHING.txt`.
Existing Wi-Fi credentials, printer profiles, themes, display settings and
SD-card data are retained by a normal P4 OTA update.
