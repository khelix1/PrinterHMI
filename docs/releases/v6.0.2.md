# PrinterHMI v6.0.2

Release date: 2026-08-05

PrinterHMI v6.0.2 is a reliability and operator-management update for the
v6.0.1 ESP-IDF 6.0.2 / ESP-Hosted 3.0.5 platform.

## Added

- Reworked the Moonraker discovery popup around the shared operator popup,
  themed status, selectable rows and semantic actions.
- Discovery now checks Moonraker ports 7125, 7126, 7127 and 7128 during one
  IP-range pass and publishes every discovered endpoint.
- Added `REMOVE SELECTED` to Manage Printers with a shared danger-style
  confirmation. It deletes only the panel's saved profile, health state and
  cached preview. Klipper, Moonraker, printer configuration and printer files
  are not modified.

## Fixed

- Prevented an unreachable active Moonraker from blocking the HMI runtime task
  during WebSocket reconnects. Reconnect/discovery sends are non-blocking, and
  the automatic WebSocket reconnect owner is allowed to recover without an
  overlapping synchronous HTTP fallback.
- Moved inactive-printer preview and health HTTP requests to a lower-priority
  worker so unreachable saved profiles cannot stall touch input or navigation.
- Subscribed the WebSocket transport to `virtual_sdcard.progress`, the actual
  file-position completion value, instead of relying on stale M73/slicer
  progress when it is available.
- Reset progress, duration and layer fields at a new job boundary so a newly
  started print does not show values from the previous print while Moonraker
  publishes its first status updates.

## Validation

- Built the ESP32-P4 application with `tools/build_idf6_hosted3.sh`.
- Verified normal HMI operation with disconnected Moonraker recovery.
- Verified confirmed removal of a non-final saved printer profile.
- Verified new print progress/layer state starts fresh rather than inheriting
  a previous job's values.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 6.0.2
- ESP-Hosted P4 and C6: 3.0.5
- ESP Wi-Fi Remote: 1.5.3
- LVGL: 9.5.0
- OTA partition layout: unchanged

## Installation

If the C6 already runs ESP-Hosted 3.0.5, install
`PrinterHMI-v6.0.2-ota.bin` normally. The complete release archive also
contains normal P4 and C6 full-flash images plus checksums and `FLASHING.txt`
for initial installation or direct recovery. Normal OTA installation retains
Wi-Fi credentials, printer profiles, themes, display settings and SD-card
data.
