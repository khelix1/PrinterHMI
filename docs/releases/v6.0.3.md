# PrinterHMI v6.0.3

Release date: 2026-08-05

PrinterHMI v6.0.3 refines the operator experience around Settings, OTA source
selection and precision Z calibration.

## Added

- Added Settings > About PrinterHMI at the bottom of the Settings page. The
  shared operator popup presents the actual running firmware version and build,
  software acknowledgements, and creator credit for khelix.
- Expanded the shared guided Manual Probe surface used by Probe/Z and Axis
  Twist with symmetric TESTZ controls: 1.00, 0.10, 0.05, 0.01 and 0.005 mm.
  The fine controls remain fully inside the shared popup content area.

## Fixed

- Stable and Nightly OTA catalog installations no longer overwrite the saved
  Custom OTA URL. A selected GitHub asset is used only for the current update;
  the custom server remains available when the operator returns to Custom OTA.

## Validation

- Built the ESP32-P4 application with `tools/build_idf6_hosted3.sh`.
- Verified the About popup uses shared popup/theme primitives and fits the
  Settings scroll layout.
- Verified Custom OTA URL persistence after Stable and Nightly catalog use.
- Verified Probe/Z and Axis Twist fine TESTZ controls through 0.005 mm.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 6.0.2
- ESP-Hosted P4 and C6: 3.0.5
- ESP Wi-Fi Remote: 1.5.3
- LVGL: 9.5.0
- OTA partition layout: unchanged

## Installation

Install `PrinterHMI-v6.0.3-ota.bin` through Stable OTA, Nightly OTA, or a
Custom OTA URL. Existing Wi-Fi credentials, printer profiles, themes, display
settings, custom OTA URL and SD-card data are retained.
