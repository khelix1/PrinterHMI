# PrinterHMI v6.0.4

Release date: 2026-08-07

PrinterHMI v6.0.4 finalizes resilient live-state reporting for a
multi-printer Moonraker cell. The chooser now distinguishes a reachable
Moonraker service from a printer that is genuinely ready to operate.

## Fixed

- Kept the operator UI responsive while the active Moonraker WebSocket
  reconnects. Inactive profile HTTP work is isolated from that recovery path.
- Kept inactive-printer work serialized and bounded so an unreachable saved
  profile cannot repeatedly contend for the ESP-Hosted transport.
- Made inactive cards report a current Klipper print state only after both
  Moonraker and Klipper report ready.
- Made a missed inactive probe retire its positive presentation immediately as
  `VERIFYING...`, then require a confirmation failure before `OFFLINE`.
- Made reachable Klipper startup report `VERIFYING...`; explicit Klipper
  `shutdown` or `error`, or a confirmed unreachable endpoint, reports
  `OFFLINE`.
- Preserved health only for unchanged configured endpoints and refreshed all
  configured profiles automatically without requiring operator selection.

## Validation

- Built the ESP32-P4 application with `tools/build_idf6_hosted3.sh`.
- Verified active Moonraker disconnection does not stall the UI.
- Verified inactive ready, Klipper-starting, no-MCU, unreachable and recovery
  states on the target panel.
- Verified chooser updates occur automatically for every configured profile.

## Compatibility

- Hardware: JC1060P470C-I/W ESP32-P4 panel with ESP32-C6 networking
- ESP-IDF: 6.0.2
- ESP-Hosted P4 and C6: 3.0.5
- ESP Wi-Fi Remote: 1.5.3
- LVGL: 9.5.0
- OTA partition layout: unchanged

## Installation

Install `PrinterHMI-v6.0.4-ota.bin` through Stable OTA, Nightly OTA, or a
Custom OTA URL. Existing Wi-Fi credentials, printer profiles, themes, display
settings, custom OTA URL and SD-card data are retained.
