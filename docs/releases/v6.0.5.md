# PrinterHMI v6.0.5

PrinterHMI v6.0.5 improves first-time Moonraker printer onboarding while
preserving explicit operator control.

## Added

- Empty printer chooser slots now open the matching Add Printer profile form.
- Verified discovery rows show the Moonraker-reported printer host name when
  available, alongside the IP address and port.
- Selecting a verified discovery result pre-fills the name of a fresh profile.

## Changed

- Discovery tests ports 7125 through 7128 concurrently for each candidate
  address, then performs HTTP verification only for reachable endpoints.
- A verified, Klipper-ready endpoint is labelled READY. Discovery never saves
  a profile, switches the active printer, or changes the Klipper configuration.
- Existing custom profile names remain unchanged when a discovery result is
  selected; saving remains an explicit operator action.

## Validation

- Built with the canonical ESP-IDF 6.0.2 and ESP-Hosted 3.0.5 build path.
- Exercised the nightly OTA update path after the onboarding changes.
