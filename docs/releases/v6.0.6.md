# PrinterHMI v6.0.6

Released 2026-08-08.

## Highlights

- Added optional encrypted configuration backups using AES-256-GCM and a passphrase-derived key.
- Encrypted backups include configured Moonraker API keys; ordinary JSON backups intentionally do not.
- Added progress feedback while creating encrypted backups and verifying encrypted restores.
- Improved backup restore safety with preflight validation and recoverable file replacement.

## Compatibility

Existing plain backups remain supported. Encryption is opt-in and does not alter live printer profiles or settings unless an operator confirms a restore. Losing an encrypted-backup passphrase prevents recovery from that particular file.

See [Encrypted Configuration Backups](../ENCRYPTED_CONFIGURATION_BACKUPS.md) for operation and recovery guidance.
