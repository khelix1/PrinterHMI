# PrinterHMI v6.1.0

Released 2026-08-09.

## Highlights

- Optional per-profile HTTPS/WSS Moonraker connections with verified local CA
  trust, explicit Standard mode, and no silent HTTP downgrade.
- Per-profile `.pem` selection from the SD-card root with automatic port-443
  selection, supporting multiple printers and Moonraker instances.
- A public generic Nginx installer that validates Moonraker before changes,
  creates correct IP/DNS certificate SANs, verifies HTTPS, exports the CA, and
  rolls back the previous Nginx site if validation fails.
- Persistent active-printer E-STOP with named stop/recovery feedback and an
  accessible Klipper firmware-restart action.
- A clear attended-operation confirmation before PID heater heat cycles.

## Upgrade notes

Existing profiles remain Standard HTTP/WSS unless Secure mode is explicitly
selected. See [Secure Moonraker Setup](../SECURE_MOONRAKER_SETUP.md) before
enabling a secure profile.
