# PrinterHMI v6.2.0

## Operator Shell

- New selectable Operator Shell theme with a purpose-built eight-item operator rail.
- Dashboard and Printer use compact print-cell layouts designed for the 1024x600 ESP32-P4 display.
- Files, Tools, Console, Drybox, and Settings have been verified on-panel for layout and touch fit.

## Live camera

- Active-printer MJPEG streams can be discovered from Moonraker or configured per printer profile.
- Camera viewing uses persistent streaming, PSRAM-first frame handling, and ESP32-P4 hardware JPEG decode.
- Dashboard includes a camera preview toggle when the active printer has a configured stream.

## Reliability and workflow

- Files opens immediately and automatically loads the Moonraker library after its first frame.
- File-list fetches retry transient failures automatically.
- The splash is retained above all startup UI work to eliminate page-construction flashing.
- Printer profile and camera setup use shared popup keyboard controls.
