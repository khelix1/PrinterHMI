# PrinterHMI v6.3.0

## Camera v2

- Added a persistent per-printer Camera v2 catalog for up to four camera streams.
- Added secure Moonraker webcam discovery and import using the active profile's
  HTTPS/API-key policy.
- Added continuous MJPEG live viewing with PSRAM-first frame and task storage,
  hardware JPEG decoding, fullscreen viewing and an identified active-camera control.
- The Camera page now rebuilds through the active runtime theme and keeps its
  Configure, live-status, camera identity and Fullscreen controls within the
  live-view card.
- Camera discovery now has a PSRAM-first TLS task stack, avoiding the secure
  handshake overflow seen on constrained internal task stacks.
- The Camera page clears a prior frame immediately when the active printer has
  no configured camera, preventing cross-printer stale imagery.

## Startup display

- Startup keeps the panel dark during BSP initialization, reveals a stable
  splash frame once, uses a solid splash backlight, then restores the saved
  operator brightness after the handoff.

## Validation

- Verified on the ESP32-P4 target: secure Moonraker camera discovery, live
  continuous camera view, fullscreen, profile switching without stale frames,
  Camera configuration, cold startup splash, OTA and normal operator pages.
