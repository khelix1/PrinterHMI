# PrinterHMI v6.4.0

## Camera management

- Added direct management for up to four cameras per printer profile.
- Name each camera, select its slot directly, set a default, and remove it with a confirmation.
- FIND imports every Moonraker webcam and retains the names reported by Moonraker.
- USE CAMERA applies the current camera immediately, so the Camera page updates without a navigation round-trip.
- The saved default camera is used on the first Camera-page open after boot.

## Upgrade

- OTA update from v6.3.0 is supported.
- Existing Camera 1 stream settings remain compatible and are automatically shown as the first named slot.
- Other camera slots and their view/default settings are stored per printer profile.

## Validation

- Build and flash the v6.4.0 image.
- Verify Camera Setup: rename, direct slot selection, FIND, DEFAULT, and REMOVE.
- Reboot after choosing a non-first default camera and confirm it opens first.
