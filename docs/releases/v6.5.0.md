# PrinterHMI v6.5.0

## Highlights

- Added a single-card first-run Setup Center with selectable Welcome, Wi-Fi,
  Printer, Camera, and Complete steps.
- Discovery flows for Wi-Fi networks, Moonraker printers, and cameras stay
  inside the Setup Center and reuse the normal discovery and popup modules.
- Improved offline behavior so setup remains usable when Wi-Fi is unavailable,
  while retry and discovery feedback remain visible.
- Hardened camera setup and OTA transitions, including safe camera shutdown
  before an update and clearer camera discovery/test actions.
- Continued shared UI localization and fallback-font coverage for setup and
  operator-facing strings.

## Verification

- ESP-IDF 6.0.x hosted P4 build completed with the repository warning gate.
- Public-tree and version audits pass before publishing.
- The stable publisher produces both the P4 OTA image and complete P4+C6
  flash stack with SHA-256 manifests.

## Upgrade

- OTA from v6.4.1 is supported.
- Existing printer profiles, camera profiles, themes, and Wi-Fi settings are
  preserved.
- If first-run setup is needed later, open it again from Settings.
