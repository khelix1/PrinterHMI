# PrinterHMI v6.5.1

Released 2026-08-22.

## Summary

This maintenance release hardens the ESP32-P4 display startup and wake path.

## Changes

- Increased the JD9165 hardware reset settle timings.
- Added an explicit panel-on command after JD9165 initialization.
- Preserved the v6.5.0 stable camera, dashboard, and operator-shell behavior.

## Validation

- Canonical ESP-IDF 6.0.2 P4 build.
- Public-tree, version, documentation-link, dependency-lock, and firmware-size audits.
- Startup, power-cycle, and display wake verification on the ESP32-P4 panel.
