# PrinterHMI v6.5.2

Released 2026-08-22.

## Summary

This maintenance release completes Dashboard Camera/Thumbnail behavior across printer profiles and themes.

## Changes

- Camera/Thumbnail visibility now refreshes when the active printer changes.
- The toggle remains interactive when a newly selected printer provides a camera.
- Camera/Thumbnail placement is kept inside the active-print card across all themes.

## Validation

- Canonical ESP-IDF 6.0.2 P4 build.
- Public-tree, version, documentation-link, dependency-lock, and firmware-size audits.
- Camera visibility and interaction verified while switching printers and themes.
