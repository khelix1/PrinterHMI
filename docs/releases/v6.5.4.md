# PrinterHMI v6.5.4

## Summary

This maintenance release fixes the Dashboard print ETA display.

## Fixed

- Dashboard print ETA now represents the estimated completion time rather than
  the current clock time.
- Completed prints no longer cause the ETA banner to keep advancing with the
  current time.

## Verification

- Dashboard ETA behavior verified on target hardware.
- v6.5.3 baseline remains unchanged except for the ETA correction.
- Release documentation and version audits updated for v6.5.4.
