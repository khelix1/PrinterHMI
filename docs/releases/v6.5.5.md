# PrinterHMI v6.5.5

Release date: 2026-10-03

## Summary

This maintenance release fixes Dashboard previews for browser-started prints
and incorporates the verified Dashboard and Printer telemetry corrections.

## Fixed

- Dashboard previews retry transient metadata or thumbnail-download failures
  without requiring a trip to the Printer page. Retries are five seconds apart,
  limited to four attempts per job/endpoint, and stop once a preview is ready.
- Live preview requests wait for Wi-Fi and Moonraker readiness.
- Dashboard and Printer layer estimates use the shared live G-code Z state.
- Virtual-SD progress remains authoritative across partial WebSocket frames;
  HTTP fallback parses the corresponding object explicitly.
- Dashboard and Printer percentage displays consistently truncate to integers.

## Verification

- The user confirmed the preview fix after a firmware build and hardware test.
- The telemetry corrections were previously merged as verified device work.
- Focused coordinator tests covered retry timing, metadata recovery, failed
  downloads, task overlap, success deduplication, attempt limits, and reset.
- Publication requires source/version/dependency audits, the canonical
  ESP-IDF 6.0.2 P4+C6 build, firmware-size and application-warning checks,
  and verification of the packaged SHA-256 checksums.
