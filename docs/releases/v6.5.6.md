# PrinterHMI v6.5.6

Release date: 2026-10-04

## Summary

This release expands Tools calibration and diagnostics while tightening action
and profile ownership checks. Existing file-preview improvements remain included.

## Added

- Probe Accuracy with 5/10/20 samples and Klipper's final statistics.
- Devices → ENDSTOPS with idle-only, two-second live queries.
- Macro search, up to eight detected parameter fields, two additional named
  fields and final command review before execution.
- Calibration → Motion: current runtime limits, hardware-geometry
  rotation-distance calculator and TMC driver currents/status/temperature.

## Fixed

- Tools dispatch rechecks printer readiness and workflow requirements.
- Calibration sessions reject stale profile responses and handle timeouts.
- Confirmed Bed Mesh profile save and SAVE_CONFIG use one ordered script.
- Motion driver-selector copies compile with optimized restrict warnings enabled.

## Verification

Host checks cover action/session policy, macro parameters/catalog, endstop
response IDs/timeouts, partial motion/TMC updates and calculator validation.
Real LVGL 9.5 headless checks cover Motion button layout, readouts, driver states,
calculator interactions and profile guards with normal and larger text.
The repaired Motion source passes optimized host compilation with warnings as
errors. Source architecture, version, dependency, public-tree and document-link
audits pass. These checks do not substitute for target-device acceptance.
Publication builds the canonical ESP-IDF 6.0.2 P4+C6 stack, checks application
warnings and image size, and verifies packaged SHA-256 checksums before pushing.
Target-device checks are listed in [Testing](https://github.com/khelix1/PrinterHMI/blob/v6.5.6/docs/TESTING.md).

- `PrinterHMI-v6.5.6-ota.bin` and its SHA-256 checksum.
- `PrinterHMI-v6.5.6-full-stack.tar.gz` and its SHA-256 checksum, containing
  P4 OTA/full-flash images and ESP-Hosted 3.0.5 C6 recovery images.
