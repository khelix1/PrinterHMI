# PrinterHMI v7.0.0

Release date: 2026-10-20

## Summary

PrinterHMI 7.0.0 brings the Studio interface and LVGL 9.5 modernization across
the ESP32-P4 operator panel. Dialogs, keyboards, previews, controls and setup
workflows now share consistent layout and ownership rules.

## Interface and operator workflows

- Responsive dialogs, consistent keyboard layouts and visible cursors, pinned
  actions, input scrolling and larger-text support across themes.
- Printer chooser/setup, connection security, API keys, CA selection and camera
  configuration workflows.
- Filament runout recovery and active-print temperature/fan controls.
- Files browsing, print confirmation, metadata and preview navigation;
  camera/preview lifecycle handling and corrected PPA alignment/cache behavior.
- Tools, calibration, motion/driver diagnostics, Console filters and command
  review, telemetry and system-wide notification levels.
- Backup/restore progress, encrypted-backup success confirmation and incorrect
  passphrase feedback. New backups preserve TLS and primary camera settings.
- Build channel/revision identity, OTA review, transfer metrics and cancellation.

## Correctness and security fixes

- Retire stale callbacks, fence actions to their printer/profile, reject
  duplicate dispatch and handle failures/retries across operator dialogs.
- Preserve the active CA after rejected imports or failed persistence. Require
  TLS for endpoint-only requests when a matching configured profile requires it.
- Validate endpoint URLs and restored credentials, encode print filenames as
  JSON, and confine authenticated Moonraker HTTP requests to their endpoint.
- Reject incomplete backup serialization on allocation failure, excessive SD
  JSON nesting, embedded NULs and trailing JSON data.
- Reject oversized passphrases/firmware URLs instead of truncating them, and
  handle release-browser mutex allocation failure.

## Validation and known limitations

The reviewed development tree passed 78 individual host suites and eight
source/documentation audits. Tests include real LVGL/cJSON checks and SDK fault
fixtures; they do not establish target hardware behavior. Stable publication
builds the complete P4+C6 stack, checks firmware size and application warnings,
and verifies packaged SHA-256 checksums before publishing.

An intermittent panic/rollback observed when opening OTA after encrypted backup
has no matching panic trace and remains unconfirmed. None of the fixes above
is claimed to resolve that event. Further physical printing/recovery and soak
coverage has not been established by the host review.

HTTP/WS and local HTTP OTA remain available for the existing trusted-LAN
workflow. Secure Boot, flash encryption and encrypted NVS are not enabled by
this release. Encrypted SD backups protect their payload; plain backups omit
Moonraker API keys but store camera URLs as plaintext configuration. CA
certificates and additional camera catalog slots remain panel-local. Configure
TLS and select the intended CA when restoring onto another panel.

Details: [Testing](https://github.com/khelix1/PrinterHMI/blob/v7.0.0/docs/TESTING.md)
and [Security review](https://github.com/khelix1/PrinterHMI/blob/v7.0.0/docs/SECURITY_REVIEW.md).
