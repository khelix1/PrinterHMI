# PrinterHMI v7.1.0

## Summary

PrinterHMI 7.1.0 improves everyday file browsing, printer switching and setup,
and consolidates the stale-code cleanup and UI lifecycle work following 7.0.0.
It targets the JC1060P470C-I/W ESP32-P4 panel with ESP-IDF 6.0.2, LVGL 9.5.0
and ESP-Hosted 3.0.5.

## Improvements since 7.0.0

- Faster Files row previews through smaller thumbnail selection, revision-aware
  RAM reuse and bounded decoded SD caching. Cached previews remain useful across
  reboots, with corruption checks and printer/profile ownership fences.
- Dashboard filenames use the space above print progress, with long-name
  scrolling and normal/large-text spacing.
- Available Bed Mesh can be viewed during printing or pause. Calibration and
  profile-changing actions retain their idle-only guards.
- Printer switching avoids unnecessary preview/page reloads and rejects stale
  connection results that caused repeated offline/online transitions.
- Quiet mode retains genuine connection-loss warnings; recovery clears them
  silently. Notification level preferences and older stored values remain readable.
- Setup Center completion indicators cover the configured steps, with safer
  callbacks, replacement dialogs and teardown.
- Calibration, toolhead, telemetry, Network and shell ownership/refresh fixes
  reduce stale references, duplicate actions and redundant UI writes.
- Remove obsolete rewrite scripts, unused modules/interfaces, alternate preview
  paths and dead state. Active controls, credential/backup migrations, source
  inventory and build/release tools remain covered by regression checks.

## Scope

The experimental 3D G-code/solid viewer and Linux Theme Maker are not included.
The existing 3D Bed Mesh workspace is included. Earlier 7.1.x-dev numbers identify
individual development batches; they do not imply those experimental features
are part of this stable release.

## Validation and update notes

Host regression suites cover native LVGL layouts/lifetimes, preview/cache
ownership, decoding, connection races, notification policy, setup completion,
backup validation/rollback and security boundaries. Source inventory, parked-
viewer boundary, version/public-tree and updater recovery checks pass. Operator
feedback accepted the development batches through v7.1.55-dev. Host checks do not
establish target hardware behavior or a new long-print soak result.

Stable publication builds the final P4+C6 stack and checks application warnings,
firmware size, dependency locks and package checksums before publishing. Final
version firmware still needs a panel smoke check. See [Known Issues](https://github.com/khelix1/PrinterHMI/blob/v7.1.0/docs/KNOWN_ISSUES.md)
and [Security review](https://github.com/khelix1/PrinterHMI/blob/v7.1.0/docs/SECURITY_REVIEW.md) for limitations. This release does not
claim a new security certification or changes to Secure Boot/flash encryption.

Existing configuration, profiles and backup migrations remain supported. Preserve
a backup before updating. Review TLS/CA and camera settings when restoring onto
another panel; certificate and camera-catalog limitations remain documented in
[Settings backup](https://github.com/khelix1/PrinterHMI/blob/v7.1.0/docs/ENCRYPTED_CONFIGURATION_BACKUPS.md).

## Assets

- `PrinterHMI-v7.1.0-ota.bin` and its `.sha256` checksum.
- `PrinterHMI-v7.1.0-full-stack.tar.gz` and its `.sha256` checksum, containing P4
  OTA/full-flash images, C6 recovery images, manifest and checksums.

Use the OTA binary for the existing panel OTA workflow. The full-stack archive
also supports recovery and reproducible stack installation.
