# PrinterHMI v7.1.1-dev

Experimental branch: `feature/gcode-viewer-3d`. Branch baseline is v7.1.0-dev;
each delivered patch increments the patch number, retaining `-dev`.

This first patch adds a read-only 3D toolpath prototype under Tools, with a
Files shortcut, offline sample and bounded streaming parser/renderer. See
[G-code viewer](../GCODE_VIEWER.md) for supported input, limits and validation.
No stable release, merge, firmware flash or hardware performance claim is made.
