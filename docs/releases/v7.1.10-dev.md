# PrinterHMI v7.1.10-dev

The normal Files > 3D view workflow now automatically prepares a shaded solid from
supported G-code extrusions. File loads default to Solid when memory permits. The
initial path preview stays usable; layer, Lines and Travel views retain their paths.
No slicer modification, conversion, extra file or companion service is required.
The previous manual STL/PHM chooser is parked and excluded from firmware.

A bounded sampled extrusion envelope uses all generated paths in the supported
prefix, reads a complete SD cache or automatically replays the original HTTP file,
and rejects replayed content changes. Width/height tags are retained when supported;
otherwise nominal dimensions apply. Exterior extraction, bounded smoothing and
shared vertex normals improve the solid appearance. Budgets trigger coarsening or
an explicit fallback to the existing path preview. Details reports the cell size.

Host parser, cache, automatic volume, loader and real LVGL checks pass, including
no-SD replay, source mismatch, cancellation, hole preservation, rendering guards and
cleanup. ESP-IDF build and tablet memory, timing and appearance remain unverified.
This approximates deposited material; it does not recover original CAD or guarantee
high-resolution-thumbnail fidelity. Small features/gaps may merge and supports remain.

Apply the source updater on feature/gcode-viewer-3d. Build with
`./tools/build_idf6_hosted3.sh`; OTA image: `build-idf6-hosted3/PrinterHMI.bin`.
Then choose your usual G-code file in Files and tap 3D view.
