# PrinterHMI v7.1.11-dev

Fix solid-view presentation: keep Solid shaded during drag/pinch, ignore stationary
touch samples, and build camera snapshots offscreen before publishing complete
frames. New gesture positions coalesce into the next frame instead of continually
restarting the current one. Renderer work remains split across timer ticks; controls
can cancel or replace stale work. One extra 617 KiB PSRAM frame is allocated lazily;
allocation failure retains Lines and supports retry.

Status now identifies SOLID MESH, SOLID SURFACES or SOLID PATHS, with automatic
preparation progress/failure placed before coverage details. Path fallback can look
thin at whole-model scale; this patch does not change reconstruction geometry.

Host real LVGL checks compare visible Lines/Solid images, offscreen publication,
stationary touch, camera coalescing, allocation failures and ownership in five themes.
Tablet performance and the user's automatic-solid result still require verification.
ESP-IDF is unavailable in the host workspace. Build with
`./tools/build_idf6_hosted3.sh`; OTA image: `build-idf6-hosted3/PrinterHMI.bin`.
