# PrinterHMI v7.1.12-dev

Accelerate automatic solid rendering without reducing its geometry or canvas
resolution. Triangle depth/shading gradients are stepped incrementally and a small
shade lookup replaces per-pixel color conversions. Only generated outward-wound
exterior meshes enable rear-face culling; research imports remain two-sided.

Unfinished frames continue after 5 ms rather than the idle 33 ms interval. Existing
bounded work slices, complete-frame publication, camera coalescing and shaded
interaction remain. Logs now report complete frame latency. No extra frame/mesh
allocation is added. Initial G-code volume preparation is unchanged.

On the host, a 60-view benchmark of the same 46,368-triangle G-code solid measured
8.83 -> 4.30 ms/frame with identical final-view silhouette and slight shade
quantization. This does not predict ESP32-P4 timing. Host ASan/UBSan volume/mesh,
loader and five-theme real LVGL checks cover culling equivalence, open holes,
clipping, incremental output, scheduling, gestures, ownership and cleanup.

Tablet speed and appearance need verification. ESP-IDF is unavailable here.
Build with `./tools/build_idf6_hosted3.sh`; OTA image:
`build-idf6-hosted3/PrinterHMI.bin`.
