# PrinterHMI v7.1.13-dev

Use a lighter shaded solid while orbiting or pinching, then automatically restore
the unchanged full-detail model when all fingers lift. Automatic preparation
attempts a separate mesh capped at 4,096 triangles. Gesture frames draw at half
width and height and scale into the existing canvas. Camera framing and complete
frame publication remain consistent; a new gesture can interrupt a stale full frame.

No allocations occur during gestures. Optional clustering retains about 185 KiB
and uses up to 264 KiB of temporary scratch. Failure keeps the full mesh and lower
pixel-resolution interaction available. The gesture child shares its root's lifetime
and is released on close/reload/replacement. Small features may briefly soften or
merge in the gesture mesh; releasing restores full detail. Initial full-mesh
preparation is unchanged, with optional clustering added afterward.

A 60-view host ring benchmark measured 46,368 triangles at 2.98 ms/frame for full
rendering versus 2,258 triangles at 0.51 ms/frame for gesture rasterization. This
excludes upscaling/LVGL/LCD costs and does not predict tablet FPS. Host ASan/UBSan
and five-theme real LVGL checks cover clustering bounds, cancellation/OOM/cleanup,
child selection, pinch guards and exact full-detail pixel restoration.

Tablet speed/appearance remain to be verified. Build with
`./tools/build_idf6_hosted3.sh`; OTA image: `build-idf6-hosted3/PrinterHMI.bin`.
