# PrinterHMI v7.1.14-dev

Up to now keeps the shaded automatic mesh, cuts it at the selected height and
fills its cut face on the closed full mesh while preserving holes. It is a height
section of the approximate envelope, not exact cumulative toolpaths for non-planar
motion. Gesture cuts remain lighter, two-sided surfaces; release restores the full
capped section. An optional 39 KiB stencil is reused; allocation failure is labelled
and retains the open shaded cut.

Changed one-pixel drag samples immediately wake rendering, with Bed Mesh horizontal
sensitivity. Subsequent mesh frames invalidate old/new model bounds instead of the
entire canvas and stop per-frame status churn. Details separates raster/publish
costs from the last display cycle and flush callbacks. LCD/PPA settings are unchanged.

Bed Mesh remains inspectable during printing/paused when data is available. The
open page refreshes snapshots so late-arriving mesh data appears during the print;
unchanged snapshots do not redraw. Offline cached data is labelled. Calibration
and profile changes retain their idle, connection and owner restrictions.

Host ASan/UBSan and five-theme native LVGL tests cover sections/caps/holes, raster
bounds, first-pixel response, reduced flushed pixels, mode/preparation/lifetime
behavior, live Bed Mesh updates and blocked print-time actions. Target speed and
appearance need verification. Build with `./tools/build_idf6_hosted3.sh`;
OTA image: `build-idf6-hosted3/PrinterHMI.bin`.
