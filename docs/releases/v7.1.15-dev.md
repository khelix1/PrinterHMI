# PrinterHMI v7.1.15-dev

Fix apparent one-finger zoom caused by angle-dependent mesh auto-fit. The camera
now uses a cached, rotation-independent bounding sphere. Full and gesture meshes
share the same fit; orbit changes orientation while pinch and +/- own user zoom.
Reset/presets retain their existing explicit reset behavior. Initial framing can
differ slightly from the previous angle-specific fit.

There is no per-frame geometry scan or extra gesture allocation. Fast interaction,
section caps, reduced invalidation and print-time Bed Mesh viewing remain in place.
Host checks cover angle-independent scale across 80 views/zoom settings, shared
full/gesture fitting, one-finger zoom invariance, working pinch and raster guards.
Tablet verification remains pending. Build with `./tools/build_idf6_hosted3.sh`;
OTA image: `build-idf6-hosted3/PrinterHMI.bin`.
