# PrinterHMI v7.1.16-dev

Keep the prepared solid in Single and Travel combinations. All shows the exterior;
Up to keeps the body below the selected height; Single keeps a height interval.
The active layer now draws its actual extrusion/infill paths as shaded strands,
with gaps, instead of an artificial filled cap that hid the pattern. This displays
the selected layer's material, not all historical internal infill below it.

Solid Up to now reads matching SD layer detail as Single does. Until available,
or without SD, retained paths are used and reduced coverage is labelled. Travel
adds gray depth-tested moves in the same camera without replacing or rescaling the
solid. Explicit Lines remains available for path inspection. Thin strands can still
look thin at whole-object scale or edge-on; they are not a wireframe fallback.

Exterior, active material and travel phases publish only a finished frame. Damage
bounds include active strands; travel transitions invalidate conservatively. All
keeps its lighter gesture mesh, while height sections retain full geometry at half
pixel resolution during movement. The unused cap stencil is removed from the UI.

Host parser/raster/loader and five-theme native tests cover the mode/camera matrix,
cached infill adoption, shaded strands/gaps, depth-tested travel and height clipping.
Tablet appearance and performance remain to be verified. Build with
`./tools/build_idf6_hosted3.sh`; OTA image: `build-idf6-hosted3/PrinterHMI.bin`.
