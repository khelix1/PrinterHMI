# PrinterHMI v7.1.17-dev

Solid Up to and Single now draw the selected layer's material as closed octagonal
extrusions with elliptical cross-sections, shaded sides and filled end faces. Path
width and height determine the geometry, using nominal dimensions when unavailable.
This replaces the earlier screen-space infill strokes. Real gaps remain visible;
flat caps and overlapping joins are a display approximation of deposited plastic.

Inspection zoom increases from 4x to 16x. Pinch preserves the model point under the
two-finger centroid; plus/minus zoom around the canvas center. Camera presets and
Reset reframe the model. One finger still only orbits. At whole-model scale, real
nozzle-width infill can remain subpixel and look like lines: zoom and tilt to see
its height and side faces.

Extrusion rendering uses transient vertices in batches of 64, with no persistent
layer mesh or per-frame heap allocation. The existing All exterior fast path is
unchanged. Selected-layer rendering adds triangle work; target speed is unmeasured.
SD exact-layer reads and labelled reduced-coverage fallbacks are unchanged. Only
the selected layer's internal material is exposed, not every prior infill layer.

Host tests cover extrusion end faces, physical height changes, shading/gaps,
clipping and raster guards at 16x, shifted section holes, and anchored pinch in the
five-theme native UI. Full ESP-IDF build and tablet verification remain pending.
Build with `./tools/build_idf6_hosted3.sh`; OTA image:
`build-idf6-hosted3/PrinterHMI.bin`.
