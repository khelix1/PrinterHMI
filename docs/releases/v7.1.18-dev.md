# PrinterHMI v7.1.18-dev

Focus this correction on the exposed selected-layer interior in Solid Up to and
Single. Its extrusion faces now use the same gold material as the exterior body,
replacing cyan tool colors that made it resemble explicit Lines. The existing
exterior geometry, All view and thin tool-colored Lines rendering are unchanged.

When a physical extrusion cross-section is too small to resolve, Solid enlarges
its displayed width to at least 3 pixels and height to at least 2 pixels. Its top
remains at the source path Z; its centerline is unchanged. This is a readability
aid, not measured geometry: unresolved narrow gaps may appear closed. Once zoom
makes the source width/height exceed those thresholds, physical dimensions apply.
Half-resolution gesture staging scales the aid to preserve its display size.

Host raster tests cover fit-scale gold shading, separated gaps, filled ends, true
height at close zoom, staging scale, depth and damage guards. Native tests exercise
the actual cached-interior Solid versus Lines toggle in five themes, in addition
to the mode/camera matrix and gesture checks. Full ESP-IDF build and target visual/
performance checks remain pending. Build with `./tools/build_idf6_hosted3.sh`;
OTA image: `build-idf6-hosted3/PrinterHMI.bin`.

Already-loaded matching SD layer detail is retained when comparing with Lines,
so returning to Solid restores the same full interior without another detail read.
Changing the layer, file or printer still retires it through existing ownership.
