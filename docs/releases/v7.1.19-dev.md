# PrinterHMI v7.1.19-dev

The Solid Up to screenshot showed raised, disconnected-looking top strips. The
preceding ellipse-based strands produced valleys and moving highlights even where
dense neighboring paths should form a skin. Exposed selected-layer material now
uses flattened eight-sided beads: a broad planar top spans 95% of the width,
narrow bevels meet side faces, and each face has consistent directional lighting.
The top remains at source path Z; width and height still come from source dimensions
or nominal defaults, subject to the existing minimum display thickness aid.

A small endpoint overlap improves local path joins: it is bounded by a quarter of
segment XY length, a quarter of displayed width, and half of displayed height.
Only XY endpoints extend; their Z values stay unchanged. This is a display join
approximation, not new source motion. Sparse infill remains path-based with open
bays. There is no synthetic filled cap, role classification, or original-CAD claim.
No new mesh allocation, triangle count, shader palette, or All-view work is added.
The approximate exterior shell is unchanged.

Host checks reproduce the old raised-strip skin on a simple body. A regression
requires neighboring nominal 0.45 mm paths at 0.42 mm spacing to produce a level,
continuous top; it fails with the prior rounded renderer. Tests also retain sparse
gaps, tilted face shading, physical end dimensions, bounded staged rendering and
pixel/depth guards. Native viewer checks cover five themes and Solid/Lines routing.
The photographed file and tablet performance still require target verification.

Build with `./tools/build_idf6_hosted3.sh`; OTA image:
`build-idf6-hosted3/PrinterHMI.bin`.
