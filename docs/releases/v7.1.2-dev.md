# PrinterHMI v7.1.2-dev

On `feature/gcode-viewer-3d`, reverse horizontal drag in the native viewer.
Rightward drag decreases yaw and leftward drag increases it. Add Top, Front
and 3D presets in the same control batch. Presets restore 1x zoom while keeping
layer/Travel choices. Vertical drag and the existing controls retain their behavior.

Build with `./tools/build_idf6_hosted3.sh`. The OTA image is
`build-idf6-hosted3/PrinterHMI.bin`. This wrapper selects the verified IDF,
ESP-Hosted patches, SDK configuration and PPA settings.

The user confirmed the v7.1.1-dev wrapper build worked. This patch adds native
pointer checks for both drag directions; corrected tablet feel remains a
hardware verification step.
