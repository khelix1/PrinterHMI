# PrinterHMI v7.1.20-dev

Reproduced the remaining top-layer separation with the supplied Sermoon D1 clip
G-code: 1,780 paths, 47 layers, Up to 42/47 at Z8.40, and 0.19935 mm shell cells.
The exact paths sit inside the slightly expanded/smoothed generated shell. Removing
the old full cap left a narrow open ledge between the detailed layer and that shell.
Flattening the beads alone could not close it.

Solid Up to/Single now draws a narrow inside contact band at the top cut plane.
The band is based on 1.5 shell cells projected into the camera, found using a
horizontal/vertical erosion of the section mask. Its final pixels always intersect
the original even/odd mask, so it cannot fill the section's holes or bridge outside
that outline. The deep interior remains open for actual sparse infill; a whole filled
cap is not restored. This remains a display approximation of a sampled shell.

The viewer optionally retains 39,840 bytes of PSRAM mask at 952 by 332. Failure to
allocate it preserves the original open-cut rendering and Solid stays usable.
The mask is reset per frame, reused at gesture resolution, and released on close.
No per-frame heap allocation or All-view rendering phase is added. The mask and
bounded scanline phase add work to selected-layer sections; target cost is unmeasured.

In the host reproduction, the new join closed 906 background seam pixels at 4x zoom,
with zero added pixels outside the section mask. Tests cover hollow sections,
inside-only fills, partial versus full caps, incremental equivalence, mask guards,
missing-mask fallback, optional-mask allocation failure and five native UI themes.
Full firmware build and tablet appearance/speed still require verification.

Build with `./tools/build_idf6_hosted3.sh`; OTA image:
`build-idf6-hosted3/PrinterHMI.bin`.
