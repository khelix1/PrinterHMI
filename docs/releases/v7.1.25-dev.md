# PrinterHMI v7.1.25-dev

The reported slowdown was specific to Up to: All already used a small gesture mesh,
while Up to scanned the full exterior during every drag/pinch frame. Up to now uses
the same optional shaded gesture mesh, clipped at the selected Z, with actual
selected-layer material and optional gray travel in the matching camera.

Single avoids a coarse body that could erase a thin slab. During movement it draws
only the actual shaded selected-layer extrusion faces and optional travel, at the
existing half resolution. On release both modes restore the full exterior section,
contact band and source material at full resolution. No persistent layer mesh or
per-frame heap allocation is added. Moving Up to cut contours can be coarser, and
its exact contact join returns on release. Missing gesture meshes keep the prior
full-body fallback. Single's material coverage still follows cached or labelled
reduced source coverage.

The all-route audit also caught Lines inheriting mesh interaction bookkeeping when
a prepared mesh existed. Interaction staging is now gated to actual Solid frames,
including the case where Solid buffers are unavailable. Lines stays full resolution
and never touches missing Solid buffers.

Expanded native checks cover Solid/Lines x All/Up to/Single x Travel off/on x
Top/Front/3D with drag, pinch and release in five themes. Rendered buffers are
compared with complete reference rasters, including exact settled sections and
material-only moving Single. Tests also cover merged surfaces, path fallback,
missing gesture mesh, missing section mask and missing Solid staging buffers.

For the supplied clip, the host Up to movement body dropped from 61,064 to 2,627
triangles; 60-view half-resolution raster times changed from 3.60 to 1.04 ms/frame.
This is host evidence, not a tablet speed or visual-quality guarantee. Check Up to
and Single on target after Preparing mesh finishes. Loading/security improvements
and the v24 raster rollback are retained. Build with `./tools/build_idf6_hosted3.sh`.

Extrusion-role colors are queued for the next batch; live following remains paused.
