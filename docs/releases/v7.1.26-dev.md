# PrinterHMI v7.1.26-dev

Tablet feedback confirmed better movement, with All still smoothest. Up to and
Single previously passed every surviving triangle through polygon clipping,
even when all three vertices were already inside the visible height interval.
Those interior triangles now use the same direct raster path as All. Crossing
triangles keep the original clipping and contact-mask path. Layer selection,
active material, gesture quality, settled detail and memory use are unchanged.

A differential ASan/UBSan check compares the shortcut against a separately compiled
original clipping path over 192 frames: Up to and thin slabs, vertex-exact cut
heights, multiple cameras, extreme zoom/pan, culling, masks and incremental batches.
Pixels, depths and section masks match exactly. The five-theme native viewer
route/gesture/fallback matrix also passes. No tablet speed guarantee is inferred
from host timings; All still has less work because it has no selected-layer overlay.

Build with `./tools/build_idf6_hosted3.sh`. Extrusion-role colors remain next;
live print following remains paused.
