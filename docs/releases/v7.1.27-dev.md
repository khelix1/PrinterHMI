# PrinterHMI v7.1.27-dev

The supplied tablet photos report Up to at 1604.2 ms total / 530.4 ms raster / 12.7 ms
publish, versus All at 111.4 / 57.1 / 10.4 ms. Display cycle/flush callback timings
were 16.6/7.5 ms and 21.3/5.2 ms respectively. These are last-completed-frame samples,
not movement FPS: release can replace a movement sample with a settled redraw.
The heavy file has 150607 source paths, 87624 shell triangles and 1486 cached paths
in the selected layer. The extra measured cost is mainly CPU rendering and time
between render batches; the photos do not yet separate cut-shell and active-material costs.

This batch removes redundant selected-layer work: projected bead vertices no longer
run the normal/specular shader whose result was replaced by planar face lighting;
invisible side faces are rejected before normal normalization and lighting. It
preserves geometry, lighting of visible faces, source material, gold solids, gaps,
minimum cross-section, layer/travel semantics and exact settled detail. No new
allocation or sampling is added. The generic All raster path is unchanged.

A frozen v26 material reference verifies 96 dense 1500-path frames byte for byte
for pixels, depths and damage bounds, with full/half resolution, camera sides,
slopes, vertical paths, small arc chords and extreme zoom. The 192-frame cut/slab
reference test and five-theme native viewer route/fallback checks also pass.
Host material timing in the sanitizer test improved modestly (8.86 to 7.82 ms/frame);
that synthetic case is not the user's camera-mount G-code or a tablet speed promise.
This patch does not claim to resolve the reported movement slowdown.

Details now begins with body/material/travel stage durations. The last completed
movement sample is preserved across the full-detail settled redraw and labelled
All, Up to or Single. The sum of stages excludes publish and scheduling gaps;
frame elapsed time includes waits between batches and other UI work. Fresh file
or mesh adoption clears movement samples. This makes the next tablet observation
identify which stage needs a larger change.
