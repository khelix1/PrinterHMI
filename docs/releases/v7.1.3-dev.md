# PrinterHMI v7.1.3-dev

On `feature/gcode-viewer-3d`, add a layer-inspection control batch:

- Pinch zoom follows Bed Mesh sensitivity/smoothing and its lift-all-fingers
  guard. The existing Bed Mesh and LVGL pointer paths remain intact.
- Drag the layer slider to jump directly to a Z level; Layer -/+ fine-step.
- Single shows the selected layer. Up to shows all layers through that layer.
- All returns to the whole model. Reset also restores the default view/mode.
- Top/Front/3D retain the chosen layer and inspection mode.
- Endpoint steps disable where unavailable; the slider disables for fewer than
  two layers, and layer controls disable for models containing only travel.
- Transition travel is assigned to the layer it approaches.

Native pointer/raster checks cover all five themes, slider endpoints/midpoint,
both modes, preset preservation, Reset, travel ownership and empty/single-layer
edge cases, pinch lifecycle/bounds and raw touch delivery. Tablet feel and actual-file performance remain verification steps.

Build with `./tools/build_idf6_hosted3.sh`. The OTA image is
`build-idf6-hosted3/PrinterHMI.bin`.
