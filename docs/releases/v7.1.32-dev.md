# PrinterHMI v7.1.32-dev

Second source-cleanup batch on `chore/stale-code-cleanup`, based on the delivered
v31 Files-cache implementation that the operator verified across reboots.
Retires 35 unused APIs and roughly 870 production lines across three related groups:
the unconstructed Dashboard status panel/no-op updater chain, the separate Phase-1
thumbnail state/path prototype, and unused popup/layout/session factories.
Two obsolete Dashboard module files are deleted. Current banner/cards, thumbnail
worker/results/PNG storage, Files cache, full-resolution lightbox and 3D renderer
keep their active owners. No runtime speed or firmware-size gain is claimed.

Reference evidence and retained code are listed in [CODE_CLEANUP.md](../CODE_CLEANUP.md).
Real-LVGL Dashboard/offline/camera/status observers, popup/keyboard/modal safety,
telemetry/chart updates, native preview/cache, aspect pipeline and viewer checks
pass. A new ASan/UBSan test executes the actual thumbnail manager's ownership,
worker success/retry and failure paths. The legacy-only telemetry test block is
removed in favor of the current Dashboard-owner tests; Printer/chart coverage stays.
Source membership, public-tree and version audits also pass.

The updater preflights all files and provides backups, rollback and guarded recovery.
No commit or push is performed. Build with `./tools/build_idf6_hosted3.sh`, then check
Dashboard status/progress, Printer/Tools popups, Files thumbnails and full-screen
preview. Full ESP-IDF and panel smoke validation remain required for this batch.
