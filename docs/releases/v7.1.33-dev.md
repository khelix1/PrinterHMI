# v7.1.33-dev — independent fixes and cleanup

This development branch is based on main bce8481b2e9ee7ecdb9353f696a3e954fd7d4d1e,
without the experimental G-code/solid viewer or Theme Maker. The existing viewer
and cleanup branches remain preserved for future work. Version numbering resumes
at 7.1.33-dev to distinguish this build from the previously tested 7.1.32-dev build;
it does not imply that intervening experimental features are included.

## Included

- Files row previews: smaller source selection, revision-aware RAM reuse, bounded
  persistent decoded SD cache, corruption checks and profile ownership fences.
- Studio Dashboard filename uses the space above progress, with circular scrolling
  and normal/large-text spacing.
- Available Bed Mesh is visible during printing/paused and updates when it arrives.
  Calibration and profile-changing actions keep their original idle-only checks.
- Both stale-code cleanup batches, including 59 completed source rewrite scripts,
  three unused source/header pairs and unconsumed thumbnail/popup/leaf APIs.
  Active status, toolhead, previews, persistent data migration and build helpers remain.

## Validation

Native LVGL checks exercise Files/Tools/Network layouts, real preview ownership,
file-list loading, Dashboard states/camera, shared popups, telemetry, current page
construction and live Bed Mesh. Cache and thumbnail-manager checks use ASan/UBSan.
Source inventory and viewer-boundary tests check that the branch has 157 firmware
sources and no viewer hooks or sources. The guarded updater is checked for drift,
repeat application, recovery and rollback after a simulated write failure.

Files loading was verified by the operator, including across reboots, on the
source branch. This newly separated build still needs its own panel verification.
The ESP-IDF toolchain is unavailable here; build with
`./tools/build_idf6_hosted3.sh`, then test Files, Dashboard, Bed Mesh and toolhead
controls before committing and merging. No stable release is published here.
