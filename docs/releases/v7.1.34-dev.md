## Validation

Existing host checks exercise toolhead actions, Bed Mesh availability, chooser
refresh, themes, active/aspect previews, camera frames, setup/backup dialogs,
TLS/profile validation, readiness, JSON controllers and encrypted worker failures.
The tests mock ESP-IDF transport/NVS/RTOS APIs; they do not constitute a complete
firmware build or validate real PSA encryption. Inventory, viewer-boundary,
version and public-tree audits are also run.

The updater requires the current-main revision and this branch name. It checks
source fingerprints and protected inputs, preserves unrelated sdkconfig edits,
backs up replacements, supports dry runs/recovery, and rolls back ordinary write
failures. No commit, push, merge, build or flash is performed by the updater.

The full ESP-IDF toolchain is unavailable here. Build with
`./tools/build_idf6_hosted3.sh`, then check startup, printer switching, Files
across a reboot, toolhead extrusion, Bed Mesh, camera and settings. No intentional
UI or runtime behavior change and no measurable performance gain is claimed.
