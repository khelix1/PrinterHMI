# v7.1.36-dev — printer-switch preview continuity

The operator reported a second-load effect when switching to a printing printer.
The existing profile callback reset previews, restored a validated cached canvas,
and then reset previews again through its configuration-change helper. Separately,
the first live printing/paused update destroyed even a matching cached RGB canvas
before starting fresh metadata/thumbnail work. The Dashboard constructor already
reuses its root; these are avoidable preview retire/restore operations.

The profile callback now performs one configuration/preview reset before runtime
reset and cached restoration. Live preview coordination keeps an existing matching
canvas until replacement while still fetching fresh metadata and forcing a fresh
thumbnail. RAW PNG-backed images are retired before PNG memory is freed. Other
filenames and profile-invalidated canvas names still clear immediately. No cached
telemetry or old-printer image is substituted as live state.

## Validation and target gate

`printer_switch_refresh_test.py` compiles the actual configuration/profile/chooser
bridges with fault-injected SDK mocks under ASan/UBSan (LeakSanitizer disabled in
this host environment). It checks one reset before cached restoration, cache miss,
reselection, failed selection, profile health and explicit retest. The same test
fails against v35's bridge ordering. Real LVGL coordinator regressions check
matching-canvas retention during printing/paused verification and failed retry,
unchanged pixels, READY suppression, mismatched files and profile-invalidated
names. Existing reentrant deletion/slot replacement coverage remains.

Existing active/aspect preview, cache ownership, Dashboard offline/camera,
chooser and profile-discovery bridge tests also run. Host validation does not
measure target switch speed. Build with `./tools/build_idf6_hosted3.sh` and switch
repeatedly between idle/printing/paused printers, including ones using the same
filename. Check a cache miss, offline destination and Camera/Thumbnail toggle.
The full firmware toolchain is unavailable here.

The updater applies after v7.1.35-dev on `chore/stale-code-cleanup-main`, with
source guards, backups, rollback and recovery. It performs no commit, push, merge,
build, flash or printer action. Viewer branches remain parked.
