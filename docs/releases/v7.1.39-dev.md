# v7.1.39-dev — compatibility plumbing cleanup

This batch removes the no-op Dashboard filename setter, empty Printer filename
handles, ignored live-status arguments/context metadata, ignored Camera setup
callbacks and Drybox fill argument, and an unused polling macro. It retires one
no-op API, six unused globals/context fields and eleven ignored parameters.
Actual filename display remains in the shared banner, and layer resolution,
preview, live values, tuning, Camera ownership and Drybox actions remain.

All current production/header/host callers are updated together. Existing test
assertions for dispatch, acknowledgement, failure/retry, layouts and deletion
remain. No persistent data or build membership change is made; source membership
stays at 157 C files. The connection, notification, preview and Files implementations
from v38 are preserved. No UI behavior, cadence or performance change is intended.

Host checks exercise native pages, tuning/direct-action safety, profiles and
Camera lifecycle, command surfaces, live-widget refresh, Dashboard/offline,
notifications, printer switching and the connection race. Inventory, viewer
boundary, version/public-tree audits and guarded updater/recovery tests also run.
The full ESP-IDF firmware toolchain is unavailable here. Build with
`./tools/build_idf6_hosted3.sh` and check Printer filename/layers/tuning, Camera
Configure/return, Drybox program controls and printing-printer switches on panel.
Quiet must still show confirmed loss and silently clear its card on recovery.

Apply incrementally over v7.1.38-dev on `chore/stale-code-cleanup-main`. The updater
performs no commit, push, merge, build, flash or printer action. Viewer and Theme
Maker branches remain parked and will need their own integration reconciliation.
