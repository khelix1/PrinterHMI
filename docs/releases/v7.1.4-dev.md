# PrinterHMI v7.1.4-dev

A single motion/file-compatibility batch on `feature/gcode-viewer-3d`.

- G2/G3 arcs: clockwise/counter-clockwise, full circles, helices, G17/G18/G19
  planes, I/J/K offsets, G90.1/G91.1 centers, signed R and relative endpoints.
- G20/G21 unit conversion, G92 including no-argument reset, explicit
  SET_GCODE_OFFSET moves and four bounded SAVE/RESTORE_GCODE_STATE slots.
- T0-T15 and canonical ACTIVATE_EXTRUDER names, independent per-tool extrusion
  state, distinct/repeating tool colors and no invented docking chords.
- Known slicer bookkeeping skips, physical line/command diagnostics, bounded
  partial/empty results and scrollable Preview details with pinned Close.
- Sample now includes T1 arc rings; a started reload clears old geometry so
  failed file loading cannot mislabel the old sample as the selected file.

Tool offsets/docking, homing and firmware-retraction motion defined outside the
file are explicitly omitted/flagged. Unknown motion stops with a reason. Preview
support does not certify that the selected printer accepts a command (R arcs,
relative arcs and inch mode are examples supported by the viewer but not stock
Klipper). See [G-code viewer](../GCODE_VIEWER.md) for limits and exact scope.

Build: `./tools/build_idf6_hosted3.sh`. OTA:
`build-idf6-hosted3/PrinterHMI.bin`. Host tests are not a target performance claim.
