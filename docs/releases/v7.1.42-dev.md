# v7.1.42-dev — Setup deferred callback cleanup

Setup Center now cancels a queued theme/text change when its center or owned
fields are deleted, releasing the busy latch that could leave reopened Setup
unresponsive. Deferred callbacks match the pending operation's epoch. Returning
old callbacks cannot consume or unlock a replacement Setup's queued choice.
Unsaved canceled choices do not write preferences or rebuild UI. Normal accepted
saves, failure/retry feedback and synchronous command protection remain.

Remove the permanently-null legacy step-window handle, its unreachable cleanup
helper and nine old patch-marker comments. Current stage and poll cleanup remain.
No persisted schema, layout, theme rendering or connection policy changes.
Quiet still shows genuine connection-loss warnings and silently clears them on
recovery. The viewer and Theme Maker remain parked; 157 firmware sources remain.

The real LVGL Setup test covers explicit/root/stage cancellation, immediate busy
release, no canceled writes/rebuilds, repeated clicks, successful next saves,
timer balance, stale callbacks and owner replacement during persistence. The
new test reproduces the stuck-busy assertion on unchanged v41. Existing Setup
layout/keyboard/Wi-Fi/camera/save-failure tests and surrounding appearance,
Settings/display, network/backup, notification, profile, Camera and Calibration
audits run, together with source/version/boundary and updater recovery checks.

Apply over v7.1.41-dev on `chore/stale-code-cleanup-main`. Build with
`./tools/build_idf6_hosted3.sh`; the full ESP-IDF toolchain is unavailable here.
Panel: Setup theme/text changes, close/reopen and navigation through Network,
Printer and Camera; Settings dialogs, printer switching and Quiet notifications.
The updater performs no Git mutation, build, flash or printer action.
