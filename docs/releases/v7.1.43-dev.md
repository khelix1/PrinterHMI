# v7.1.43-dev — Setup completion check marks

Time zone and Display were permanently marked incomplete in Setup navigation.
They now receive a check after a successful save or Continue accepting the current
values. Welcome checks after Continue; Review checks after successful Finish.
Progress survives reopen/reboot. Previously finished setups receive the new marks
without rerunning setup. Network, Printer and optional Camera retain their current
connection/configuration checks; skipping an unconfigured camera does not check it.

Progress uses one byte in the existing onboarding NVS namespace. The existing
complete key and operator preferences/backup schema remain compatible. Invalid
steps/unknown bits are rejected or masked, and duplicate marks avoid extra writes.
Failed/canceled preference saves do not mark completion. Failed marker writes offer
a retry; a successfully saved appearance still performs its required UI rebuild.

Real onboarding persistence fault/reboot checks and the native Setup completion/
layout/callback checks run, with surrounding appearance, Settings/display,
network/backup, notification and profile audits. Inventory, version/public-tree,
non-viewer boundary and guarded updater recovery checks remain required.

Apply over v7.1.42-dev on `chore/stale-code-cleanup-main`. Build with
`./tools/build_idf6_hosted3.sh`; the full ESP-IDF toolchain is unavailable here.
Panel: Setup marks after saving/Continue, close/reopen/reboot, optional Camera and
Finish/Review. Quiet connection-loss warnings remain; parked experiments stay parked.
The updater performs no commit, push, merge, build, flash or printer action.
