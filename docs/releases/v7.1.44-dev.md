Z-offset text on every 500 ms refresh. The existing widget-based value helper
preserves current text on rebuilt widgets, real changes and feedback expiry.

reading snapshots or updating UI. Current timers and NULL immediate refreshes
keep the same cadence and behavior.

panel/button state still owns tab selection; all six exact preset commands remain.

changes. Source membership stays 157; viewer and Theme Maker remain parked.

feedback expiry, owned/foreign timer snapshots, real tab state and all six hotend
presets. The new silence assertion reproduces redundant invalidation on v43.

version/public-tree, boundary and updater recovery checks also run. These host
results do not establish hardware FPS or whole-firmware speed improvements.
