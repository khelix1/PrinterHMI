# v7.1.45-dev — Network page cleanup

Network now retires cached root/field references when objects are deleted and
preserves replacement pages opened by deletion callbacks. Refresh uses the current
page epoch and avoids unchanged text/color writes. Partially deleted Studio banner
labels stay separate from the legacy banner structure.

Scan rendering rejects nested calls while clearing rows. SSID labels/callback data
are bounded to 32 bytes, including unterminated SDK records. Failed SSID allocation
leaves a disabled row with no callback. Row-owned copies are freed on deletion.

Remove three permanently-null main application editor handles, their destroy-helper
arguments and an unbound hint field. Real popup password/keyboard owners remain in
Network Tools and Setup. No persistent format, layout, transport scheduling,
connection or notification policy changes; Setup progress and parked features stay
as before. Firmware source membership remains 157.

Native Network tests cover direct deletion/late calls, field retirement, reopen,
replacement callbacks, zero invalidations over 100 unchanged polls, live transitions,
maximum/hidden SSIDs, nested scans, allocation failure and balanced row/object cleanup.
The new stale-root assertion reproduces on unchanged v44. Full responsive and
surrounding network/Settings/status/notification/Setup/switch/race checks run, plus
inventory, version/public-tree, boundary and guarded updater recovery validation.

Apply over v7.1.44-dev on `chore/stale-code-cleanup-main`. Build with
`./tools/build_idf6_hosted3.sh`; the full ESP-IDF toolchain is unavailable here.
Panel: Network close/reopen/status/port, repeated scans and password entry, Setup
network flow, printer switches and genuine Quiet connection-loss/recovery behavior.
The updater performs no Git mutation, build, flash or printer action.
