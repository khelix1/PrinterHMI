# PrinterHMI v7.1.7-dev

Add Solid/Lines display selection and eight times the preferred retained path
capacity (262,144). PSRAM allocation falls back to smaller buffers down to the
original 32,768; sampling and reduced-detail warnings remain above capacity.

Solid uses depth-tested, shaded, approximate 0.45 mm round extrusion beads.
Travel remains thin. Solid builds in bounded batches across UI ticks; Close,
layer changes and orbit can interrupt/restart it. Selected/cumulative layers, tool colors, presets and zoom
remain available. Interaction temporarily uses Lines and restores Solid after
finger release. Depth storage is allocated on demand and freed with the viewer;
failure leaves the loaded line view usable and allows retry.

This is a deposited-toolpath visualization, not an original CAD reconstruction
or watertight solid export. Bead radii are clamped to 0.65–8 pixels. Missing or
sampled paths are never filled in. Nominal width is not measured from the file.
The offline tower tapers at 0.10 mm/level and has no top/bottom skin.

Host ASan/UBSan tests cover depth/raster bounds, occlusion independent of path
order, layers/travel, 200,000 unsampled paths and memory fallbacks. Native LVGL
checks cover five themes, Solid toggle/allocation retry, orbit/pinch and cleanup.
Actual tablet performance and full-file memory pressure remain target checks.

Build with `./tools/build_idf6_hosted3.sh`; OTA image:
`build-idf6-hosted3/PrinterHMI.bin`.
