# v7.2.0-dev — Tools case lighting

Add Tools → Lighting for exactly the active printer's `output_pin case_led`.
The header action keeps the existing four Tools tiles and their geometry. The
modal has an on/off switch and a 0–100% slider. PWM outputs honor the configured
scale; digital outputs get on/off only. The current value follows Klipper's live
status, including external changes. No printer-side macro or panel preference is
required, and firmware does not change Klipper configuration.

Send brightness once on touch release. Serialize pending commands, confirm from
live output status and report rejection, short send or missing confirmation inline.
Use the existing authenticated/TLS live WebSocket without HTTP fallback or new
polling. The action is usable during printing/paused; offline, unavailable,
unknown and printer-changed states disable writes. Reconnect/Klipper restart
retire old lighting readings/configuration. Close and direct deletion retire UI
timers/fields; pending hardware commands already sent are not cancelled by closing.

Host checks exercise actual model/transport and LVGL UI, scaled/digital values,
malformed data, ownership, timeout/retry and release-only dispatch. Source/version,
parked-viewer and release boundary checks remain. Firmware sources total 159.
The target toolchain/panel is unavailable here. Build with
`./tools/build_idf6_hosted3.sh`, then verify real case_led controls, external value
changes, printer switching, disconnect/reconnect and digital fallback. Do not use
stable publication tooling for this development build.

See [Lighting guide](https://github.com/khelix1/PrinterHMI/blob/feature/case-lighting/docs/LIGHTING.md).
