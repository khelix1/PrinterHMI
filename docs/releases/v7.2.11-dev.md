# v7.2.11-dev

The tablet demo now enables Devices, Macros and Drybox using the real UI modules.
Devices shows a full first sample printer and a smaller second printer. Generic
lighting readings follow the local Lighting state. Endstop requests are replied
to locally and reflect the sample toolhead position while idle; printing/paused
requests remain blocked by the normal UI policy.

Macros provides discovered parameters, search, favorites, review and confirmation.
Nineteen sample macros on the first printer have local bounded handlers; the
second printer offers three basic macros. Only supported numeric parameters are
accepted. Invalid/unknown parameters leave state unchanged; no Jinja or arbitrary
printer macro body is executed. Heat/park/home/filament macros affect local state;
START_PRINT requires BED_TEMP and EXTRUDER_TEMP and starts a sample file only when
idle. PRINT_TEST also starts locally. The desktop retains one extra PID macro
for its existing calibration fixture. Favorites stay in demo RAM.

Drybox controls apply local PLA/PETG, Hold, Resume and Stop state. Temperature and
humidity approach illustrative targets over time. The second sample printer has
no Drybox capability. Printer switching preserves each printer's state. M112 and
error scenarios turn off simulated heaters; real printer commands are never sent.

Shared catalog/config/status builders live in printer_simulation_catalog.c.
The existing storage/client boundary remains in force: no Wi-Fi startup, SDK
HTTP/WebSocket clients, real preference writes or SD mounting in tablet demo.
Camera, Calibration and setup/service backends remain later batches.

Theme Maker preview34 uses helper capability 23. Host/controller/sanitizer checks
cover the new paths; use ./tools/build_idf6_hosted3.sh and verify on the tablet.
