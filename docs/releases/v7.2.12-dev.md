# v7.2.12-dev

The tablet offline demo enables the real Camera page, with two sample views for
the first printer and a front view for the second. The sample is labeled DEMO.
The camera picker, rotation, mirroring and fullscreen use the real firmware UI;
settings remain in demo RAM. Camera Find returns a local sample catalog and Test
succeeds only for the sample URLs. Arbitrary addresses never trigger a request.

Camera artwork is shared with the Theme Maker native preview. The tablet caches
one image in PSRAM while viewing and publishes an owned frame at most once per
second; leaving the page retires the allocation. No camera task or network
transport is started in demo mode. Allocation failure keeps the page usable.

Calibration and some setup/service workflows remain for later work. Use
`./tools/build_idf6_hosted3.sh` and test on the tablet; host tests cannot replace
an ESP-IDF build or hardware verification.
