# v7.2.13-dev

Fix the Dashboard Camera/Thumbnail toggle being covered by incoming frames or
thumbnail updates in firmware and the desktop preview. The button reads
Thumbnail while the camera is shown and switches back to Camera in thumbnail
mode. Sample camera frames are labeled DEMO CAMERA.

Tapping the Dashboard camera image opens fullscreen; dismissing it returns to
the Dashboard camera view. Fullscreen opened from the Camera page continues to
return to that page. A profile change while fullscreen prevents restoration of
the old printer feed. Navigation to Camera from Printer remains available.

The desktop helper now uses the real firmware stacking order instead of raising
controls in a fixture on every tick. Hardware verification is still needed;
build with `./tools/build_idf6_hosted3.sh`.
