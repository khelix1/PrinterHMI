# v7.2.14-dev

The tablet offline demo enables Calibration through the real page and dialogs.
The full sample printer offers simulated screws/gantry, probe accuracy,
manual probe/Z, axis twist, shaper/resonance/accelerometer, PID, pressure
advance, motion diagnostics and a custom PID_BED sample macro. The limited
printer reports fewer capabilities. Commands are bounded and only simulated;
no printer transport, actual calibration, config save or restart occurs.

Calibration sessions and command capabilities reset on printer changes or
connection loss. Printing and paused scenarios block calibration. Results and
manual probe movements belong to the sample session. The Apply & restart
confirmation clearly explains that a demo save does not affect a printer.

Theme Maker preview37 has native helper capability 26. The host-only demo UI
harness uses the real demo calibration command handler, while the desktop keeps
its existing fault fixtures. Build with `./tools/build_idf6_hosted3.sh` and
verify on the tablet; host tests cannot replace an ESP-IDF build.
