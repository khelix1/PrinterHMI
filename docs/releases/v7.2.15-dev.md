# v7.2.15-dev

Offline demo can browse sample Stable and Nightly releases and simulate a
transfer through the real OTA dialogs. Cancellation and completion report that
no firmware was changed. Custom URLs are displayed but never fetched. Real OTA
workers remain blocked in demo mode; no image is written and no reboot occurs.

Use `./tools/build_idf6_hosted3.sh` and verify on the tablet. The host test-only
firmware UI helper exercises the real demo OTA controller; target hardware has
not been tested here.
