# v7.2.19-dev

A demo usability and isolation pass covers the sample print journey across Files,
Dashboard and Printer, plus sample Network, Setup, OTA, Calibration, camera,
object, Files and service workflows. The host build uses local fixtures; the
isolation test exercises real boundary code with SDK spies. It is not a tablet
verification or proof that every external interface is isolated.

No new firmware behavior is added in this patch. Build with
`./tools/build_idf6_hosted3.sh` and verify the demo and real-printer transition
on the tablet.
