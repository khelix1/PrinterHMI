# v7.2.20-dev

The demo and Theme Maker reject pause, resume and cancellation when the
simulated print state does not permit the transition. This prevents an idle,
completed or emergency-stopped demo from becoming a print through stale actions.
The commands also require an available simulated connection.

Host state, UI and demo isolation checks cover these transitions; verify on the
tablet using `./tools/build_idf6_hosted3.sh`.
