# v7.2.23-dev

Dashboard and Printer share the same layer resolver. If a print has progressed
but the reported current layer remains zero, it can estimate the current layer
from G-code Z and layer height, or from progress and a known total. A reported
nonzero current layer remains authoritative. Estimates need a known total and
are approximate; Z hops and variable layer heights can affect them.

Host tests cover reported, zero, missing and metadata fallback layers. Build
with `./tools/build_idf6_hosted3.sh` and verify an externally started print
on the tablet.
