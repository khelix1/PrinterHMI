# v7.2.3-dev — OTA build channels

Date: 2026-10-29. Development patch based on published v7.2.0.

Local `X.Y.Z-dev` builds now identify as Development. Generated nightly versions
identify as Nightly. The stable publisher explicitly marks Stable; ordinary
unlabelled final-version local builds remain Custom.

Version ordering applies within a release channel. Switching from old Custom
`7.2.2-dev` firmware, current Development, or Nightly to Stable `7.2.0` now says
Switch to Stable, rather than claiming a downgrade. Development patch counters
are not an ordering of published stable releases. This also handles legacy
Custom-labelled development images without a separate migration setting.

Stable `7.2.0` → Stable `7.1.0` remains a downgrade; identical stable versions
remain reinstalls. Nightly builds retain date ordering, exact identity matching,
and different-build handling for different hashes on the same day. Unknown or
cross-channel identities do not claim an upgrade or downgrade. Nightly still
requires its development-build warning. Both installed and selected identities
remain visible before installation.

Host validation: firmware identity comparisons, channel CMake configurations,
real LVGL OTA confirmation flows, development/final version guards and source
membership. Transport and firmware transfer behavior are unchanged. Target
build, OTA and tablet verification remain required; the host cannot exercise
ESP32-P4 bootloader anti-rollback or physical flashing.

Build with `./tools/build_idf6_hosted3.sh` on `fix/ota-build-channels`. Do not set
the Stable channel for this development version. Stable publication remains
7.2.0 until this patch is verified and finalized. The old firmware's OTA browser
cannot be changed retroactively; the corrected behavior begins after installing
firmware containing this patch.
