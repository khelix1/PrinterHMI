# v7.2.5-dev

Theme Maker preview28 refreshes the Linux simulation against current PrinterHMI.
Tablet simulation uses the real firmware widgets without applying an editable
palette or artwork. Panel preview, Components and legacy layout authoring remain
design tools; their browser reconstructions are not parity evidence.

Setup Center now runs the real onboarding UI, including saved step checkmarks,
Wi-Fi scan/password/verification, printer editor, camera discovery/test/save,
appearance changes, review and completion. Lighting and OTA use their real UI
owners with bounded local responses. No firmware is downloaded or flashed.

The portable simulator owns command effects, thermal movement, progress, pause
and completion. Native page opens no longer reseed an existing printer state.
Scenarios and an optional clock let a user exercise states across real pages.

The runtime does not link printer/network transports. Hardware services, TLS
validation, encryption and camera feeds remain fixtures; desktop multitouch and
ESP32 display performance require their own validation. Startup splash and
graphics instrumentation are outside this interactive page simulation.

The firmware offline demo is not enabled in this release. Its future adapter
must isolate all real transports before using this model. Firmware builds use
`./tools/build_idf6_hosted3.sh`; the development build has not been target-built
in the hosted workspace.
