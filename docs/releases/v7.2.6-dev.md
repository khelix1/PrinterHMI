# v7.2.6-dev

Theme Maker preview29 checks the 15 native page routes and control dialogs in
Studio and Operator. A repeated Studio-to-Operator Printer-page rebuild exposed
stale Studio-only target-label references in shared firmware code. Initialization
now clears the card structure before creating either layout. The failure was
reproduced with host ASan/UBSan before this fix.

Desktop Escape now invokes the foreground dialog's actual Close, Back, Cancel,
Keep or Dismiss callback. It does not directly delete an arbitrary modal. In
particular, escaping simulated OTA transfer first cancels its timer; closing the
result then permits a new release-browser session. Nested firmware review, URL
keyboard, Lighting, notification, dropdown, Camera and lightbox owners retain
their own cleanup.

The page/popup matrix, existing native checks and simulation checks are host
validation. They do not establish pixel-by-pixel physical display equivalence.
The optional host sanitizer build instruments application/fixture objects; a
reused LVGL archive is not itself instrumented. Leak detection is unavailable in
the hosted runtime. Target firmware validation still uses
`./tools/build_idf6_hosted3.sh`. Firmware offline-demo mode remains disabled.
