# v7.2.7-dev

Operator's Lighting button was positioned relative to the Tools page root,
partly above its header. It now aligns to the header's right side and reserves
a separate column beside the title and subtitle. Hiding the action restores
the labels' full width. Page resizing reapplies the same layout.

Lighting remains visible only when the active printer exposes `case_led`.
Studio placement, connection/ownership guards and the actual Lighting dialog
are unchanged. Theme Maker preview30 contains the same shared UI fix.

The native layout was rendered and checked on the host. Firmware target
validation uses `./tools/build_idf6_hosted3.sh`. Offline firmware demo mode
remains disabled.
