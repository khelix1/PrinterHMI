# v7.2.8-dev

Selectable offline demo foundation. Open **Printers > Demo > Start demo**,
then confirm **Restart**. Return using **Printers > Demo > Exit demo > Restart**.
The mode choice persists across reboots. No printer command is sent when entering
or leaving; a real printer's independent print job keeps running.

Demo starts with temporary sample profiles and default settings; appearance can
be changed for the current demo session. The only real NVS write is the
explicit boot-selection flag. Wi-Fi startup, SD mounting, live runtime/status
workers and app HTTP/WebSocket creation are disabled. Factory reset, backups,
OTA and network discovery are blocked with an explanation.

Dashboard, Printer controls, Lighting (first sample printer only), six scenarios
and a sample Bed Mesh are included. Files, Camera, Calibration, Devices, Macros,
Drybox and setup/service simulation remain later batches. Unknown commands fail
locally. These are sample states, not a physical printer emulator.

The portable model moved into `main/printer_simulation.c`; desktop preview31
links the same file and keeps its broader fixtures. No 3D viewer was imported.

Host isolation tests compile the real boundary/storage/runtime with SDK spies,
ASan and UBSan. Native dialog/page regressions are also checked. The ESP-IDF
build and physical entry/exit checks remain required on the target tablet.
