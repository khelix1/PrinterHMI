# v7.2.9-dev

This batch enables **Files** in tablet demo mode and shares its local backend
with the desktop simulation. It includes seven sample paths, folders, search,
sorting, details, thumbnail/fullscreen viewing and the real print-confirmation UI.
Choose Idle in Printers > Demo before starting a sample; a busy/offline/error
printer cannot accept another job. Cancelling confirmation leaves the job unchanged.

Sample starts use the same portable model on desktop and tablet: 30 minutes,
100 layers, PLA targets 210/60 C. Images and metadata are illustrative fixtures,
not downloaded G-code. Three geometric artworks have bounded RGB565 previews and
900x520 PNG originals. A source generator is included for reproducibility.

Demo's UI timer now updates active layers/time and publishes local previews
through the existing profile-indexed cache. Printer changes retire the old
file/preview dialogs and selected-file state. No live runtime worker, network
client, SD mounting or persistent preview cache is enabled. Live Files code
keeps its normal behavior. Camera, Calibration, Devices, Macros and Drybox demo
backends remain future batches.

Host checks cover the shared UI, sample metadata/PNG routes, invalid paths,
allocation failures, busy starts and model progress, with ASan/UBSan. Target
ESP-IDF build and touch/fullscreen/printer-switch checks remain required.
