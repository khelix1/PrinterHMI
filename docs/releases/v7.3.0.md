# PrinterHMI v7.3.0

## Offline demo

Explore PrinterHMI on the tablet with sample printers and print data. Open
**Settings > Demo** and confirm the restart to enter or exit. Demo changes use
temporary storage; returning to normal mode restarts into the saved settings.
Sample printing, file previews, camera, calibration, lighting, bed mesh,
network, setup and OTA workflows are available for exploration. OTA transfers
are simulated; backup, restore and factory reset require normal mode.

## Theme Maker

The Linux Theme Maker tablet preview uses shared firmware UI components and
offline sample data. This branch refreshes pages, dialogs, controls, navigation
and camera behavior to track the tablet more closely.

## Layer display

If a print has progressed while its reported current layer remains zero,
PrinterHMI can estimate it from G-code Z and metadata or from progress and a
known total. These estimates can differ from Mainsail, especially with Z hops
or variable layer heights. Valid nonzero reported layers remain authoritative.

## Assets

The stable release includes the OTA image, full-stack archive and SHA-256
checksums. The full-stack archive includes the P4 firmware and C6 recovery
images. See [BUILDING.md](https://github.com/khelix1/PrinterHMI/blob/v7.3.0/docs/BUILDING.md) for build and installation details.
