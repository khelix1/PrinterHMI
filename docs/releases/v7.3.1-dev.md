# v7.3.1-dev

The first post-v7.3.0 bug-pass batch binds layer metadata to its filename and
printer generation. A missing or mismatched result clears the output rather
than retaining another job's dimensions. A printer switch during fetch rejects
the result. The metadata module owns the cache; main passes validated local
values to the existing layer resolver instead of maintaining duplicate globals.

Metadata URL storage now accommodates a fully percent-encoded supported filename.
Previously, long filenames containing spaces or non-ASCII bytes could be truncated.

Host regression checks cover the real metadata module and related preview and
telemetry paths. Target build and tablet verification remain necessary. Build
with `./tools/build_idf6_hosted3.sh`.
