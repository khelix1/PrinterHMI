# v7.3.13-dev

OTA catalog input bounds. Stable tags now use the existing bounded version parser owned by `firmware_identity`; the duplicate catalog `sscanf` parser is removed. Signed/whitespace-prefixed components, oversized components and development suffixes cannot become stable catalog entries. Channel comparison behavior is unchanged.

Release catalogs must be complete JSON documents within the existing 256 KiB capture capacity and 16 nesting levels. Asset sizes, when present, must be finite nonnegative integers strictly below 2^63 before conversion to int64. Malformed entries are skipped. Missing size remains unknown/zero.

Actual catalog parsing passes AddressSanitizer, UndefinedBehaviorSanitizer and float-cast-overflow instrumentation with valid Stable/Nightly records, malformed JSON, invalid version components and size boundaries. The released parser reproduces the non-finite size conversion failure. Firmware-identity/channel tests and the actual OTA transfer fault suite pass, including cancellation, stalls, no-progress timeout, incomplete image, SDK failure and cleanup. The identity test's CMake execution is skipped when CMake is unavailable; target firmware validation remains local.

Build with `./tools/build_idf6_hosted3.sh`. On the tablet open Remote Builds, check Stable/Nightly entries and installed-build labels, and verify opening/closing the browser and cancellation behavior.
