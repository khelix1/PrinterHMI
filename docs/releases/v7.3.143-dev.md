# PrinterHMI v7.3.143-dev

- Resonance and accelerometer checks complete on their own diagnostic output. A save hint in the console cannot complete either check or enable Apply & restart.
- Apply & restart verifies the confirmation, result, connection and active printer immediately before sending SAVE_CONFIG. Repeated taps while sending are ignored.

Host verification covers read-only diagnostics, ordinary save, retry, and changes to the printer, print state, result or confirmation during dispatch.
