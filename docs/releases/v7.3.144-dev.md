# PrinterHMI v7.3.144-dev

PID heating, custom calibration macros, screw tilt and gantry leveling require a click on their current confirmation button. Before sending, PrinterHMI checks that the confirmation and active printer still match and that the printer is ready. If the confirmation is invalidated before dispatch, any prior calibration results remain available.

The host tests cover closing the confirmation or switching printers during dispatch, along with retry, normal commands and dialog layout.
