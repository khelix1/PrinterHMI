# PrinterHMI v7.3.147-dev

Filament Recovery shows the active extruder and requires reopening if the tool changes. Actions check live printer, homing, temperature, and sensor status as applicable before sending. After Resume, the panel waits for live status to leave Paused and advises checking Console before retrying if the same print remains paused after 30 seconds. Existing Klipper macros are unchanged.
