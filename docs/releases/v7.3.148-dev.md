# PrinterHMI v7.3.148-dev

Short connection interruptions no longer open offline/reconnected notification pairs. Active and background printers require ten seconds of continuous loss before opening a connection warning. Live controls still become unavailable immediately when status is lost.

The lifecycle sequence Print complete, Klipper disconnected, Klipper ready is tested explicitly. If Klipper stays disconnected while Moonraker remains reachable, a Klipper disconnected warning appears after ten seconds, including in Quiet mode. A sustained Moonraker loss still produces Printer offline. This patch does not change end-print macros or prevent a printer-side restart.
