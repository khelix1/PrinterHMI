# v7.3.17-dev

The HTTP fallback parses one bounded response before reading Klipper readiness,
temperatures, print state, progress, and layers. Field lookups stay inside the
correct object. Invalid Drybox program numbers and nonfinite measurements are
ignored. Inactive printer previews use the same structured status envelope and
preserve escaped filename characters.

File details, layer estimates and thumbnail selection now read the metadata
result object. Download paths reject overflow instead of passing a clipped
response to a parser or decoder. Text consumers also reject embedded NUL bytes.
The connection test still uses the HTTP status alone.

Host checks exercise malformed status and metadata, escaped and nested file
paths, the exact download boundary, oversized and binary-contaminated text,
and preview/cache ownership. Firmware and tablet validation remain local.
