# v7.3.18-dev

HTTP and WebSocket live measurements now share a numeric check that rejects
nonfinite or oversized values after unit conversion. Invalid partial updates
do not overwrite the last valid reading. Drybox program codes must be exact
integers in the supported selected or active range.

Toolhead positions require a complete valid coordinate set. The exclude-object
map skips invalid coordinates and overlong names, and clamps the display
projection before converting to LVGL coordinates.

Host regressions cover invalid telemetry, Drybox conversion, and map bounds.
Firmware and tablet validation remain local.
