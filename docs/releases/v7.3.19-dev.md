# v7.3.19-dev

WebSocket subscriptions encode discovered object names as literal JSON keys.
Quotes, backslashes, and control bytes cannot alter the subscription structure.
If an entry does not fit, construction fails before sending a partial subscription.

The exclude-object confirmation only sends names that can be passed verbatim
as a single G-code argument. Unsafe names remain visible for inspection.

Host tests cover key round trips, buffer exhaustion, and exclusion dispatch.
Firmware and tablet validation remain local.
