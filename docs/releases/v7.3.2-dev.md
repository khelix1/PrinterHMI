# v7.3.2-dev

File detail jobs now use the profile API-key limit and file-path limit rather
than smaller private buffers. Their URL buffer fits a fully encoded filename.
Oversized hosts, API keys and paths, and invalid ports, fail before task creation.

The real worker and shared encoder are tested with deferred task execution,
cancellation, a profile change during fetch, and task-creation failure. Address
and undefined-behavior sanitizers are enabled; leak detection is disabled by
default for restricted host environments. Build with `./tools/build_idf6_hosted3.sh`
and verify file details on the tablet.
