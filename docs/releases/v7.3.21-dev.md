# v7.3.21-dev

Stop Print and Cancel Object require the same observed print job at
confirmation time. Job transitions, active filename changes, and loss of
verified live state invalidate old confirmations. Pause and resume within
the same observed job do not invalidate them. Duplicate-send suppression
is scoped to the printer and observed job.

This guard uses observed status; it cannot distinguish an unobserved
replacement with the same filename and no intervening status change.
