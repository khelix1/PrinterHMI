# v7.3.23-dev

After an accepted Start Print request, the Files page prevents another start
on the same printer and observed job for up to five seconds while status
catches up. The guard survives closing and reopening Files. Normal readiness
checks still apply, and a rejected request can be retried immediately.
PrinterHMI does not automatically resend any request.

An open confirmation also expires when the observed job changes. Even if the
printer has returned to idle, the operator must review the file again.
