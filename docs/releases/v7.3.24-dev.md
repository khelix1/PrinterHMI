# v7.3.24-dev

Dashboard and Printer use the same Pause dispatch guard. An accepted Pause
cannot be sent again from the other page while the same job still reports
printing and the acknowledgement window is open. A replacement job does
not inherit the previous job's cooldown.

Filament Recovery checks the observed job as well as the printer before
sending commands. Reopening recovery after either changes loads the new
context. Demo job starts, completion, cancellation, and scenario changes
advance the job revision; pause and resume preserve it.
