# v7.3.27-dev

Lighting ignores a brightness drag interrupted by a reconnect or canceled
touch. Reopening Lighting on the same printer remembers the last live
brightness, and a withdrawn light clears its pending request.

Speed and Flow keep the requested value until a matching live reading arrives
or the existing timeout expires. Invalid readings and display clamping cannot
confirm a request. An observed disconnect cancels a drag in progress.
