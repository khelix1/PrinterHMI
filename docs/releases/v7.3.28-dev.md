# v7.3.28-dev

Files rows, print review, the fullscreen preview, and inactive printer previews
skip unusable thumbnail paths before selecting an image. Nested G-code files
resolve thumbnail paths from their own folder. Files rows prefer the smallest
adequate image, and other views use the largest usable original.

The shared URL encoder rejects undersized buffers instead of emitting partial
paths. Long filenames and thumbnail paths keep their complete encoded form
when they fit.
