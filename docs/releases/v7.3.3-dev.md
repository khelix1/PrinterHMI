# v7.3.3-dev

The camera connection tester rejects frame headers too short to contain their
declared dimensions. Camera discovery rejects hosts and API keys exceeding
the supported field lengths instead of probing a truncated endpoint.

The new JPEG regression reproduces against v7.3.0 and passes after the fix.
Host camera input, discovery lifecycle and demo isolation checks cover these
changes; build with `./tools/build_idf6_hosted3.sh` and verify on the tablet.
