# v7.3.33-dev

OTA now closes the cancellation window and checks for an accepted cancellation
as one operation before firmware validation. A second update cannot start
while the first opens its progress dialog or while cancellation cleanup awaits
the UI.

Plain and encrypted restores verify the complete measured file, including
end-of-file, before parsing or authentication.

This pass also exercised existing host coverage for command dispatch and retry,
filament recovery, backup UI and rollback, OTA catalog parsing, profile storage,
and reconnect races. Firmware and tablet validation remain separate.
