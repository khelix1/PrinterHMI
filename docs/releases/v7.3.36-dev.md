# v7.3.36-dev

Open **Settings > Time & region > Print progress & time** to set:

- **Progress:** relative file position, absolute file position, slicer (M73), or filament used.
- **Estimated time remaining:** File, Filament, Slicer, a combination, or Off.
- **ETA:** choose sources independently for the finish clock on Dashboard.

The File time estimate uses the selected progress fraction. The Filament estimate
uses filament consumed versus the job's planned total. The Slicer estimate uses
the slicer's planned duration minus time already printed. Selected usable
estimates are averaged. Relative file position falls back to absolute file
progress while the job's start/end metadata is unavailable. Missing slicer or
filament readings show placeholders.

Preferences are saved on the panel. Offline Demo changes are local to the demo
session. There is no synchronization with browser preferences.
