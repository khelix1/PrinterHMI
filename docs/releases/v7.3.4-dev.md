# v7.3.4-dev

Backup recovery hardening. Plain and encrypted exports now share promotion logic inside the backup service. A recovery copy left by a failed rollback or interrupted rotation is restored before another save can clear it. Failed rollback messages no longer claim recovery succeeded; partial deletion messages explain that some files may already be removed.

Host fault injection checks promotion, repeated failures, recovery, and retries against real files under AddressSanitizer and UndefinedBehaviorSanitizer. Backup parser and export/restore progress tests also pass, including successful and failed settings rollback. This does not guarantee power-loss atomicity or replace SD-card testing on hardware.

Build using `./tools/build_idf6_hosted3.sh`. On the tablet test plain and encrypted export, preflight, restore and deletion with disposable backups.
