# v7.3.41-dev

Network clears old Wi-Fi results when a scan starts, so a scan failure leaves
no stale rows to select. The result count survives periodic page refreshes,
and an empty scan shows the retry hint.

Unnamed access points no longer open a password editor with a placeholder SSID.
Named entries preserve up to 32 bytes of the advertised SSID. The inline list
and the scan popup keep separate row ownership.
