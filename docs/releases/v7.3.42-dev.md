# v7.3.42-dev

Camera tests and discovery no longer use task handles as busy flags. A worker
that finishes before task creation returns cannot leave the operation stuck
busy. Atomic result ownership prevents a new job from overwriting a result
while it is being consumed, and failed task creation leaves the operation
available for retry. Discovery clears its temporary API-key buffer after probing.

Lighting turns binary outputs fully on even if the last remembered brightness
came from a dimmable configuration.

Host checks reproduce the camera failure with the previous code and pass with
the fix. The firmware build and tablet verification remain local steps.
