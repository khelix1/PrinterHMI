# v7.3.43-dev

Live camera streaming now tracks worker ownership independently of the RTOS
task handle. An early allocation failure cannot leave Camera permanently busy,
and queue/task-creation failures leave it available for retry.

Oversized stream URLs are rejected instead of silently truncated. Failed
response headers and non-200 HTTP responses are rejected before reading video
data. A stop received during transport acquisition releases that ownership
without opening a stream.

The new worker regression test covers failure, retry, cancellation and resource
cleanup under address/undefined-behavior sanitizers. The existing Camera UI
pipeline check verifies frame lifetime and navigation separately.

Build and tablet verification remain local steps.
