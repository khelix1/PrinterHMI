# v7.3.44-dev

Manual Moonraker verification uses explicit worker/result ownership, so a fast
completion cannot leave Test Connection stuck busy and a new test cannot
overwrite a result while it is being copied. Oversized hostnames and API keys
are rejected before copying, and temporary verification keys are cleared after
probing or a failed task start.

LAN discovery also tracks its running state independently of task-handle
publication and shares running/cancellation flags atomically between the UI
and worker. Retry remains available after early completion and creation failure.

The batch adds endpoint worker regression coverage and updates older webcam
discovery/offline-navigation fixtures for task startup without a returned handle.
Build and tablet verification remain local steps.
