# v7.3.45-dev

Selecting an offline printer no longer freezes status checks for every other
printer. The existing background worker continues its short serialized health
requests and keeps retry/backoff and printer-generation fences. It defers
thumbnail metadata/download work while the active WebSocket is recovering.

The chooser displays Verifying when an inactive printer's successful live
snapshot expires instead of leaving its old Printing or Paused label visible.
Fresh readings restore the current state; confirmed failures show Offline.

A production polling regression reproduces the original issue and verifies the
fix with three inactive printers. Chooser UI and printer-switch checks also pass.
Build and tablet verification remain local steps.
