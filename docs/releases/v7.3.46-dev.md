# v7.3.46-dev

Authoritative live health updates, including demo printer ticks, now timestamp
their successful samples. The chooser can therefore distinguish fresh demo
readings from expired data. Explicit offline or unknown publications clear the
freshness timestamp, and unknown health cannot be online.

The per-profile notification observer debounces its active connection baseline
for three seconds, matching active connection notifications. A brief bootstrap
gap while selecting a printer no longer becomes a false Reconnected notice when
that printer returns to background monitoring. Confirmed loss and recovery still
produce their usual connection notifications, including the Quiet policy.

Production health-cache, notification UI and demo-isolation tests cover the
changes. Build and tablet verification remain local steps.
