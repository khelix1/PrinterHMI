# v7.3.47-dev

The Print progress & time dialog now tracks deletion of its owned fields and
Save button. Missing required fields disable Save and direct the operator to
reopen the dialog, instead of retaining stale LVGL pointers.

Disabled, unrelated and nested save events cannot submit duplicate writes.
Save completion belongs to the original dialog epoch: page replacement during
storage cannot close a replacement or overwrite its status. Storage failures
retain the selected options for retry. Closing retires ownership before deleting
objects, preserving a dialog reopened from a delete callback.

Host callback tests inject field deletion, duplicate actions, storage failures
and replacement. Build and tablet verification remain local steps.
