# v7.3.48-dev

File selection now rejects a path that cannot fit in the existing selected-file
session buffer instead of silently shortening it. Failure preserves the previous
selection and its saved cache, leaves preview state intact, and does not open a
detail dialog for a different path. Files shows a local message asking the user
to shorten the file or folder name.

Selecting a path already stored in the session uses an overlap-safe copy.

The production controller regression covers rejected requests without side
effects, exact-limit and nested paths, and aliased session input under
address/undefined-behavior sanitizers. Build and tablet checks remain local.
