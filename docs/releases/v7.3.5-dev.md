# v7.3.5-dev

Wi-Fi credential boundary fixes. Failed NVS reads now return false and clear both outputs instead of leaving stale credentials or treating a password read failure as an empty password. A successfully read empty password remains valid for an explicitly saved open network.

Boot, Setup Center, and Network share a stateless station-configuration builder that preserves all 32 SSID bytes and 64 password bytes, and rejects oversized input. Storage also rejects oversized credentials before opening NVS. Persistence stays in the credential store; the configuration builder performs no storage or connection operations.

The actual store and builder pass host fault injection under AddressSanitizer and UndefinedBehaviorSanitizer, plus Network/Setup bridge and demo-isolation regressions. The new failure-output test rejects the released store implementation. Build with `./tools/build_idf6_hosted3.sh`; verify connection and reboot reconnection on hardware. This does not make multi-key NVS writes transactional.
