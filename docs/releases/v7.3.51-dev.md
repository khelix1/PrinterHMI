# v7.3.51-dev

Thumbnail image requests now carry the owning job's captured Moonraker API key.
This covers Files rows, fullscreen previews, selected-file previews and inactive
printer previews, whose metadata requests were already authenticated. Protected
Moonraker endpoints no longer receive an anonymous thumbnail request after
successful authenticated metadata.

The selected-file download job captures its active endpoint/generation/key and
clears the temporary key on success, retirement and startup failures. Preparation
rejects a different endpoint or a generation change.

Quiet downloads clear their output pointer/length before acquiring the exclusive
network lane, so a busy-network failure cannot leave stale outputs. Existing
anonymous APIs remain available without inferring another printer's key.

Host downloader, selected-file worker, Files/fullscreen ownership and demo
boundary checks pass. Build and tablet verification remain local steps.
