# v7.3.66-dev — Fence camera discovery and report import failures

Camera discovery previously checked only the active configuration generation.
Editing an inactive printer does not necessarily change that generation, so a
completed search could import old camera results into a changed target profile.
The consumer now compares the captured target profile (configuration state,
endpoint, API key, TLS, name and camera URL) before any catalog write. Active
configuration changes also stop a queued worker before it starts its probe.
The copied profile credentials are cleared on consume/discard and creation failure.

Catalog save failures were previously ignored. The service now exposes a bounded
consumer status distinguishing waiting, received, stale and save-failed results.
The discovered count remains the number returned by Moonraker, not a count of
successful saves. A save failure can leave some cameras saved: the UI reports
that condition and permits retry. Neither the profile editor nor Setup Center
claims a successful import or proceeds with the normal result path on failure.
A discarded result retires waiting timers and restores retry actions.

The network worker still performs no persistence. Import remains in the UI
consumer, and the result slot stays reserved throughout import. Field ownership
checks run there under the existing UI serialization. This is not a transaction
across cameras, and it does not cancel a request already executing on the network.
The native simulation provider exposes the same save-failure status. Its Network
adapter now includes the shared Wi-Fi status helper; discovery owns a local LVGL
timer and updates the shared running flag instead of referencing a removed
firmware task handle. Canceled local scans retire before retry. The firmware
demo retains its existing local provider and generation guards.

Validation: the preceding worker imports results after an inactive-profile edit
and fails the new regression. Fixed ASan/UBSan worker tests cover edits to all
captured profile fields, queued generation changes, partial save failures/retry,
empty results, credential cleanup, immediate completion and reentrant starts.
Real LVGL profile and Setup tests exercise failed imports and discarded-result
retry, alongside their full layout/lifecycle suites. Moonraker discovery, endpoint
worker and demo isolation checks pass. The complete native helper builds and its
profile-discovery retry/close-reopen and Network scan workflows pass; an
ASan/UBSan adapter test covers running flags and timer cleanup. ESP-IDF build and
tablet checks remain local.
