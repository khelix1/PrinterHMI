# v7.3.71-dev — Preserve macro values and reject stale reviews

Macro formatting previously quoted values only when they contained whitespace.
Klipper's extended-parameter parser treats an unquoted hash as the beginning of
a comment. A value such as part#2 could therefore be shortened and later
parameters silently discarded. The shared formatter now quotes hash-containing
values as well. Existing rejection of quotes, backslashes, semicolons and
control characters remains unchanged.

A regular macro review previously checked printer ownership/connectivity but
did not recheck whether its name remained in the discovered catalog. Run now
refuses unavailable names and the review action disables on refresh. The local
explanation remains in the confirmation. If the same name becomes available
again, the exact reviewed command can be retried. Existing send-failure,
duplicate-send, printer-switch and popup-retirement guards remain in place.

Exact-name lookup belongs to macro_controller: the new contains query checks
discovery and membership under its existing lock. Both regular macro reviews
and custom calibration use it. This removes the custom dialog's repeated
status/get scan while preserving its missing-selection and reorder behavior.
The lookup checks local discovered names; it does not freeze printer-side
macro definitions or hold a catalog lock across a network send.

Validation: the production formatter passes ASan/UBSan tests for comment-bearing
and whitespace values, later parameters, duplicate keys, unsafe values and every
undersized output buffer. Generated commands round-trip through comment-aware
shlex parsing. The preceding formatter loses the value suffix/later parameter.
Real LVGL command-surface tests verify removed-review rejection, disabled Run,
restored retry and the existing callback/reentry behavior. The preceding UI sends
the stale command. Catalog-storage tests cover exact membership, unavailable
catalogs and rebuilds alongside existing persistence failures. Custom-calibration,
responsive/modern macro layouts and demo checks pass. The complete native helper
builds and its parameter-review, rejected-send retry, profile-switch, unsafe-value
and additional-parameter workflows pass. ESP-IDF/tablet verification remains local.
