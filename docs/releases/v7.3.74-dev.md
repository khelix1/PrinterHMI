# v7.3.74-dev — Recover the remembered Custom OTA URL

A failed storage open or read could make Custom OTA show the fallback URL until
the tablet rebooted. Reopening the dialog now retries the read. A missing
namespace, missing key or stored empty URL still settles to the configured
default. Only a committed save replaces the remembered URL.

The OTA worker, release catalog and demo behavior are unchanged. Host checks
cover load recovery, settled defaults, failed saves and transfer behavior.
