# v7.3.75-dev — Preserve Setup progress after storage errors

Setup now retries a failed read instead of caching an empty or incomplete
checklist until reboot. Saving an individual step requires a successful read
or confirmed absence of the existing checklist, so it cannot overwrite saved
checkmarks with partial progress. A saved completion flag supersedes the
checklist. Explicit Finish still saves completion independently.

Host coverage includes recovery, failed saves, missing data and older completed
installations. No storage format change is needed.
