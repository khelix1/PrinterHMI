# v7.3.77-dev — Studio Dark accent selection

Studio Dark now uses the chosen accent for shared accent tokens and bright
action outlines. Settings chevrons, regular action borders, and the accent
chooser's selection outline update when the saved choice is applied.

Theme Default retains the Studio palette and its existing custom-theme color
routing. Backgrounds and warning, success, and danger colors retain their own
tokens. Other themes retain their existing accent behavior. The preference
format and save flow are unchanged.

The host appearance test chooses all five overrides through the real popup,
checks the resolved Settings colors, and returns to Theme Default.
