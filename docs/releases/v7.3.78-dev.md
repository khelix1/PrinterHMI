# v7.3.78-dev — Keep cameras with their printer

Adding a printer to an unused slot now clears leftover secondary camera URLs,
names, view settings, and the default camera selection before saving the new
printer. A cleanup error stops the save so it can be retried. Existing profile
edits keep their camera settings, as do the other printer slots.

The host storage test covers delete and reuse, a failed cleanup and retry, and
reloading the new profile. This change applies to adding printers through the
profile editor.
