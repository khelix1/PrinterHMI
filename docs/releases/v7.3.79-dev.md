# v7.3.79-dev — Reset preferences for removed cameras

Removing an individual camera now clears its saved rotation and mirror
preferences. If it was the explicitly selected default, that selection is
cleared so a replacement does not automatically inherit it. Normal fallback
still chooses the first configured camera. Editing a configured camera keeps
its view settings and default selection.

The storage test covers both primary and secondary cameras, a failed preference
read, removal and re-add, and preservation of another camera’s preferences.
